# マップ制作・3D生成

`TileMapLayer` による制作用マップの編集規約、コンパイルと検証、3Dへの変換を定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 移動とイベントの挙動 | `spec/40-dungeon.md` |
| フロアとイベントの配置データ | `data/floors.csv`, `data/floor_events.csv`, `data/chest_rewards.csv` |
| カメラ以外の画面表示 | `tech/presentation.md` |

---

## 1. 編集用シーン（MAP-0xx）

| ID | 規則 |
| --- | --- |
| MAP-000 | 各 `scenes/floors/*.tscn` のルートを `FloorAuthoring(Node2D)` とし、`Terrain(TileMapLayer)` を1枚置く。 |
| MAP-001 | 各フロアを独立したシーンとする。同一シーンの実行時複製で済ませない。 |
| MAP-002 | 2Dタイルは32×32pxとし、共通のTileSetを参照する。 |
| MAP-003 | 座標0〜29の900セルをすべて明示的に埋める。空のセル、外周の通行可能セル、範囲外のセルはいずれも検証エラーとする。 |
| MAP-004 | TileSetのcustom dataには `tile_kind:String` のみを置く。 |
| MAP-005 | custom dataはタイル定義で共有されるため、宝箱のIDや階段の接続先を入れない。 |
| MAP-006 | 専用のエディタプラグインを必須にしない。標準のタイルペイントとResourceインスペクターで編集できる構成とする。 |

## 2. タイル種別とイベント（MAP-1xx）

| ID | tile_kind | 通行と表示 | 対応するイベント種別 |
| --- | --- | --- | --- |
| MAP-100 | wall | 不可。壁の立方体 | なし |
| MAP-101 | floor | 可。床 | なし |
| MAP-102 | door | 開くまで不可。扉 | door |
| MAP-103 | shortcut | 開通まで不可。扉。指定側から初回開通 | shortcut |
| MAP-104 | chest | 不可。床と宝箱 | chest |
| MAP-105 | inscription | 不可。床と石碑 | inscription |
| MAP-106 | stairs_up / stairs_down | 可。床と階段の図形 | stairs |
| MAP-107 | town_exit | 可。床と出口の表示 | town_exit |
| MAP-108 | link | 可。床と接続通路の表示 | link |
| MAP-109 | warp | 可。床の上の魔法陣 | warp |
| MAP-110 | boss | 可。床の上の敵シンボル。進入で戦闘 | boss |

| ID | 規則 |
| --- | --- |
| MAP-120 | 個別のイベントは `data/floor_events.csv` に `CellEventDef` として登録する。 |
| MAP-121 | 床1セルにつきイベントを1個までとする。 |
| MAP-122 | 地形上の特殊タイルとイベント種別を対応させる。 |
| MAP-123 | タイルを移動した場合、イベントの `cell` も更新する。 |
| MAP-124 | 階段とlinkには移動先の `floor_id` / `cell` / `facing` を登録する。到着先は通行可能でなければならない。 |
| MAP-125 | 相互のリンクが成立しない場合は検証エラーとする。 |
| MAP-126 | `town_exit` は街、`warp` は全体ID `warp_depths`、`boss` は敵IDを指定する。 |
| MAP-127 | `shortcut` の `unlock_from` は、そのセルから見た開通許可側の差分とする（南なら `Vector2i(0, 1)`）。 |
| MAP-128 | 宝箱の報酬に経験値を設定しない。 |

## 3. コンパイルと検証（MAP-2xx）

| ID | 規則 |
| --- | --- |
| MAP-200 | `get_used_cells()`、`get_cell_tile_data(cell)`、`TileData.get_custom_data("tile_kind")` で読み取る。 |
| MAP-201 | 走査の順序を y昇順 → x昇順 に固定する。 |
| MAP-202 | コンパイル結果の `FloorGrid` は、30×30のセル配列と、座標からイベントへの辞書で構成する。 |
| MAP-203 | 3Dの生成、移動の判定、ミニマップは、いずれも同一の `FloorGrid` を参照する。 |

検査項目（MAP-210〜MAP-219）。

| ID | 検査 |
| --- | --- |
| MAP-210 | 900セルがすべて埋まっている |
| MAP-211 | イベントIDに重複がない |
| MAP-212 | タイル種別が既知のものである |
| MAP-213 | イベントの座標と種別が地形と一致する |
| MAP-214 | 出入口の相互対応が成立している |
| MAP-215 | ボスと魔法陣が規定の位置にある。魔法陣は第2ダンジョンの1Fのみに存在する |
| MAP-216 | 宝箱に有効な報酬が設定されている |
| MAP-217 | 出現編成の参照が有効である |
| MAP-218 | 未開通の近道を通らずに、開始地点からボスへ到達できる。通常の扉を開ける前提で階段へ到達できる |
| MAP-219 | 第1ボスが未撃破の状態で第2ダンジョンへ到達する迂回路が、全体のグラフ上に存在しない |

| ID | 規則 |
| --- | --- |
| MAP-220 | 制作時の手順を「ペイント → イベント設定 → 検証スクリプトの実行 → ゲームの再起動で確認」とする。 |
| MAP-221 | ホットリロードと実行中のマップ変更を初回版では扱わない。 |

## 4. 3D生成（MAP-3xx）

| ID | 規則 |
| --- | --- |
| MAP-300 | セルの寸法を2m、壁の高さを3mとする。 |
| MAP-301 | セル `(x, y)` の中心を `Vector3(2*x, 0, 2*y)` とする。北を -Z、東を +X とする。 |
| MAP-302 | カメラをセル中心から高さ1.5mに置く。FOVを70度、nearを0.05、farを60mとする。 |
| MAP-303 | 通行可能なセルに2m四方の床メッシュを置く。wallには2×3×2mの `BoxMesh` を置く。 |
| MAP-304 | 扉・宝箱・石碑・魔法陣・階段は、簡単なプリミティブで識別できる表示とする。 |
| MAP-305 | 天井を初回版では設けず、背景を暗色にする。 |
| MAP-306 | 扉を開けたら扉のメッシュを非表示にする。床は残す。 |
| MAP-307 | 宝箱は開封した状態で色を変える。 |
| MAP-308 | ボスのシンボルは、そのボスが存在する状態でのみ表示する（TWN-600）。 |
| MAP-309 | マップの再読込時も、永続状態から表示を再構築する。 |
| MAP-310 | カメラを `Node3D` の子とする。移動の可否は `FloorGrid` で判定し、`CollisionShape` を必須としない（DNG-009）。 |
| MAP-311 | 現在のフロアのみを生成し、移動時に旧フロアを解放する。 |
| MAP-312 | MeshとMaterialを共通の資源として共有する。 |
| MAP-313 | 900セル規模ではまず単純な `MeshInstance3D` で実装する。計測を伴わない複雑な最適化を導入しない。 |
| MAP-314 | 光源はAmbientと `DirectionalLight3D` とし、リアルタイム影を用いない。 |
| MAP-315 | 壁と床はダンジョンごとの2組のMaterialを参照し、差し替え可能にする。 |

## 5. 仮マップの作成手順（MAP-4xx）

動作検証用の共通形状。最終的な地形はユーザーが `TileMapLayer` を編集して差し替える。

| ID | 手順 |
| --- | --- |
| MAP-400 | 座標範囲をx, yとも0〜29とする。まず900セルを壁で埋める。外周は壁のままとする。 |
| MAP-401 | y = 3, 9, 15, 21, 27 の各行について、x = 3〜26 を床にする。 |
| MAP-402 | x=26 の y=3〜9、x=3 の y=9〜15、x=26 の y=15〜21、x=3 の y=21〜27 を床にして、蛇行する一本道を作る。 |
| MAP-403 | x=10 の y=4〜8 を床にし、`(10, 6)` を未開通の近道にする。南側の `(10, 7)` から北を向いて調べたときにのみ初回開通する。開通後は双方向に通行できる。 |
| MAP-404 | `(16, 15)` を通常の扉にする。両側から開けられる。開いた状態を永続保存する。 |
| MAP-405 | `(18, 14)` に宝箱A、`(8, 22)` に宝箱Bを置く。いずれも隣接する通路から調べる。宝箱のセルは歩行できない。 |
| MAP-406 | 開始地点を `(3, 3)`、終了地点を `(26, 27)` とする。開始時の向きを東とする。終了地点から逆向きに到着する場合の向きを西とする。 |
| MAP-407 | 各フロアの `(5, 4)` に調べる会話碑を追加する。歩行不可とし、未踏破の床を開示しない。 |
| MAP-408 | 階段・接続点・魔法陣・ボスの配置は `data/floor_events.csv` に従う。 |
| MAP-409 | 門番のセルを経由しなければ第2ダンジョンへ到達できない配置とする。 |
| MAP-410 | 最終ボスの奥の通常床に重要な報酬を配置しない。 |
| MAP-411 | 最終フロアに `exit` イベントを置かない。 |

## 6. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| D02 | 6マップをコンパイルする | 各900セル、座標が範囲内、階段が相互に接続、ボスを迂回不可、魔法陣は第2ダンジョン1Fのみ | MAP-210〜219 |

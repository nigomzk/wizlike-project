# 画面・入力・素材

解像度、キー割り当て、画面レイアウト、演出、設定、素材とライセンスを定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 画面ごとの構成・操作・手動確認 | `spec/screens/` |
| 状態遷移と入力の遮断、確認ダイアログの初期選択（FLW-203）、設定画面の開き方（FLW-111〜113） | `spec/10-flow.md` |
| 初回版に含めない入力・音・3Dモデル | `spec/01-scope.md`（SCP-300, 316, 317） |
| 3Dの生成とカメラの配置 | `tech/map-authoring.md`（MAP-3xx） |
| 文章の内容 | `data/texts.csv` |

---

## 1. 解像度とレイアウト（PRS-0xx）

| ID | 規則 |
| --- | --- |
| PRS-000 | 基準解像度を1280×720、最小解像度を960×540とする。 |
| PRS-001 | ウィンドウ表示とフルスクリーンを切り替えられる。 |
| PRS-002 | UIはアンカーとContainerで画面内に収める。 |
| PRS-003 | 文字を画像へ焼き込まない。 |
| PRS-004 | 日本語の標準文字サイズを基準24px、注記を20pxとする。 |
| PRS-005 | 画面を拡大しても文字が切れないことを確認する。 |
| PRS-006 | 色だけで状態を区別しない。文字またはアイコンを併記する。 |
| PRS-007 | ボタンにフォーカス表示を付ける。長い一覧をスクロール可能にする。 |

| PRS-107 | UI項目の移動 | 矢印キー、Tab / Shift+Tab |

| ID | 規則 |
| --- | --- |

## 3. 各画面（PRS-2xx）

画面ごとの構成と配置規則（PRS-2xx）は `spec/screens/` の各画面文書に置く。PRS-206はTWN-102と重複するため欠番とした。

---

## 4. 設定（PRS-4xx）

| ID | 規則 |
| --- | --- |
| PRS-400 | 設定項目はマスター音量（0〜100、初期値70）とフルスクリーン（ON/OFF、初期値OFF）とする。 |
| PRS-401 | 設定は即時に保存する。 |
| PRS-402 | 設定は5つのゲームスロットで共有する。 |
| PRS-405 | 設定は `user://settings.cfg` に保存する。進行中のセッションが存在しない状態でも読み書きできる。 |

---

## 5. 演出（PRS-5xx）

| ID | 規則 |
| --- | --- |
| PRS-500 | 移動の演出を0.15秒、旋回の演出を0.12秒とする。 |
| PRS-501 | キーの長押しは、演出の完了後に0.12秒間隔で繰り返す（DNG-007）。 |
| PRS-502 | 戦闘の1行動あたりの表示を0.3秒を基準とする。 |
| PRS-503 | 報酬と会話は決定の入力で進める。 |
| PRS-504 | 演出の速度が判定の乱数と処理の結果に影響しないよう、計算の結果と表示のイベント列を分離する。 |

---

## 6. 素材（PRS-6xx）

| ID | 規則 |
| --- | --- |
| PRS-600 | 必要な画像は、街の背景1枚、顔10枚、敵の画像14枚、地形用のタイルアイコン、UIアイコンとする。 |
| PRS-601 | 初回版は自作の単純な図形・色分け・ラベルによる仮素材を許容する。 |
| PRS-602 | 画像の差し替えでロジックの変更を要しない構成にする。 |
| PRS-603 | 効果音は 決定・取消・衝突・攻撃・回復・勝利 の6種とする。簡単な自作音を許容する。 |
| PRS-605 | 外部の有料素材を必要条件にしない。 |

### 6.1 フォント

| ID | 規則 |
| --- | --- |
| PRS-610 | 日本語フォントとして [Noto Sans JP 可変フォント](https://github.com/google/fonts/blob/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf) を同梱する。本文のウェイトを400とする。 |
| PRS-611 | [SIL OFL 1.1 の OFL.txt](https://raw.githubusercontent.com/google/fonts/main/ofl/notosansjp/OFL.txt) を著作権表示ごと添付する。 |
| PRS-612 | 入手元を `THIRD_PARTY_NOTICES.md` に記載する。実装時に取得したファイルのハッシュを記録する。 |
| PRS-613 | OS既定のフォントのみに依存しない。 |

## 8. 受け入れ条件（Windows実機・手動）

| ID | 合格条件 | 根拠 |
| --- | --- | --- |
| W01 | Windows 11上でEXEから起動し、エディターなしで日本語フォント・素材・音が表示される | PRS-610, 600, 603 |
| W02 | キーボードのみ、マウスのみのいずれでも、登録・施設・出発・戦闘・保存・ロードが完結する | PRS-111, 100〜108 |
| W03 | 1280×720、960×540、フルスクリーンで、文字・ダイアログ・4人表示・敵3体が切れない | PRS-000, 005 |
| W04 | 横移動、旋回、壁への衝突、階段、魔法陣への到着で視点がずれず、操作の二重受付がない | PRS-500, 501, DNG-006 |
| W05 | 通常の4人パーティで、新規開始から第1ボス・魔法陣・最終ボス・エンディング・クリア後のセーブまで到達できる | 全体 |
| W06 | 少人数での出発、死亡者を含む編成、帰還アイテム、救済、所持品満杯、全滅が仕様どおりに動作する | 全体 |
| W07 | 手順に従って `TileMapLayer` を1か所編集し、再起動後に3D・衝突・地図が同じ形に変わる | MAP-220, 203 |
| W08 | タイトル復帰や閉じる操作の未保存確認、破損スロットの表示、バックアップ復旧の表示が、理解できる日本語である | FLW-300, SAV-404, 406 |

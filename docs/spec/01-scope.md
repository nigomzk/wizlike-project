# 初回版の範囲

初回版に含めるもの、含めないものを定義する。判断に迷った場合、本文書の「含めない」に該当する機能は実装しない。

「含めないもの」の正は本文書のSCP-3xxとする。各仕様文書はこれを再掲しない。

---

## 1. 前提（SCP-0xx）

| ID | 規則 |
| --- | --- |
| SCP-001 | 対象はWindows 11、キーボードとマウス、日本語、ローカル1人プレイとする。 |
| SCP-002 | エンジンはGodot 4.5.1 Standard、言語はGDScriptに固定する（ARC-0xx）。 |
| SCP-003 | ジャンルは一人称視点のダンジョン探索RPGとする。 |

---

## 2. 規模（SCP-1xx）

| ID | 規則 |
| --- | --- |
| SCP-100 | ダンジョンは2個、各3フロアの計6フロアとする。各フロアは30×30マス。 |
| SCP-101 | 第1ダンジョンのボスを撃破すると第2ダンジョンへ接続し、第2ダンジョンの最終ボス撃破でゲームクリアとする。 |
| SCP-102 | 職業は戦士・騎士・魔術師・僧侶・斥候の5種とする。 |
| SCP-103 | 街には ギルド・教会・商店・宿屋・酒場 の5施設を置く。 |
| SCP-104 | 任意の討伐・納品クエストを計6件用意する。必須の進行条件はボス撃破のみとし、クエストの完了を必須にしない。 |
| SCP-105 | 収録するデータの件数は `data/README.md` の表を正とする。記載のない職業・スキル・装備・アイテム・敵・クエストを実装者の判断で追加しない。 |

---

## 3. 体験の優先順位（SCP-2xx）

| ID | 規則 |
| --- | --- |
| SCP-200 | 第一の面白さは、限られたHP・SP・消耗品・所持品枠を見て、探索を続けるか帰還するかを判断することとする。 |
| SCP-201 | 第二の面白さは、職業編成と戦闘攻略とする。 |
| SCP-202 | クエストは資金と消耗品を補助し、冒険を少し楽にする補助要素とする。攻略の必須要素にしない。 |
| SCP-203 | 難易度は4人パーティを基準に固定する。パーティ人数に応じて敵を弱体化しない。 |
| SCP-204 | 敵の強さをプレイヤーのレベルに合わせて変動させない。 |

## 5. 未検証であることの明示（SCP-4xx）

| ID | 規則 |
| --- | --- |
| SCP-400 | 本文書群は紙上の整合と検算のみを実施した状態である。実プレイによるバランス検証は未実施であり、面白さを検証済みとは扱わない。 |
| SCP-401 | バランスの問題が判明した場合、規則ではなく `data/` の数値のみで調整する。変更値と理由を `decisions/log.md` に記録する。 |
| SCP-402 | 未実装の機能と未実施のテストを完了として扱わない。仕様の変更が必要な場合は、実装を進めず、理由と影響を提示して判断を仰ぐ。 |

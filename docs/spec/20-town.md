# 街・施設・経済

街の初期状態、5施設の操作と料金、ゲーム日数、救済、ボスの復活を定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 冒険者の作成・編成・削除・成長・スキル習得条件 | `spec/30-party.md` |
| 所持品の容量判定と装備の可否（購入時の容量判定 INV-208 を含む） | `spec/35-inventory.md` |
| クエストの受注と報告 | `spec/60-quest.md` |
| 料金・価格の数値 | `data/equipment.csv`, `data/items.csv`, `data/skills.csv` |
| 施設画面のレイアウト | `tech/presentation.md` |

| TWN-002 | 所持金を300Gとする。 |

## 2. 施設に共通する規則（TWN-1xx）

| ID | 規則 |
| --- | --- |
| TWN-100 | すべての購入・売却・訓練・治療・宿泊・報告は、操作を確定する直前に条件を再検証し、一括で反映する。 |
| TWN-101 | 条件が不足している場合、料金・アイテム・進行のいずれも変更しない。部分的な更新を行わない。 |
| TWN-102 | 変更される項目と費用を、確定の前に表示する。 |
| TWN-103 | 宿屋と教会は、パーティに含まれていない待機者にも利用できる。 |
| TWN-110 | 登録者が0人の間は、ギルド以外の施設、ダンジョンへの出発、セーブ、メニューのいずれも利用できない。該当する項目を選択不可として表示し、「ギルドで冒険者を登録してください」と案内する。 |
| TWN-111 | TWN-110の状態はニューゲーム直後にのみ発生する。最初の1人を登録した時点で解除する（PTY-102）。最後の登録者を削除した場合は再び適用する（PTY-113）。 |
| TWN-112 | TWN-110の状態で利用できるのは、ギルドとタイトルへ戻る操作のみとする。タイトルへ戻る操作はTOWNの直下に置き、メニューの内部に依存させない（FLW-004）。 |
| TWN-113 | TWN-110により、メニューを開ける時点で登録者は必ず1人以上存在する。所持品・装備・スキル・能力・地図の各画面は、対象0人の状態を考慮しなくてよい。 |

## 3. 各施設（TWN-2xx）

### 3.1 ギルド

| ID | 規則 |
| --- | --- |
| TWN-200 | 冒険者の登録、パーティ編成、名前と顔の変更、削除はいずれも無料とする（PTY-0xx, PTY-1xx）。 |
| TWN-201 | 訓練場でのスキル習得は、職業・必要レベル・未習得であること・所持金を確認したうえで、スキルの料金で行う（PTY-4xx）。 |
| TWN-202 | 死亡している冒険者も訓練を受けられる。 |

### 3.2 宿屋

| ID | 規則 |
| --- | --- |
| TWN-210 | 登録者の一覧から生存者を1人以上選んで宿泊する。 |
| TWN-211 | 料金は1人につき `5 + 2×レベル` G とする。 |
| TWN-212 | 選んだ生存者のHPとSPを全回復する。毒は解除しない。 |
| TWN-213 | 宿泊を1回確定するとゲーム日数を1進める（TWN-5xx）。 |
| TWN-214 | HPとSPが満タンであっても、料金を払って宿泊できる。 |
| TWN-215 | 死亡者のみを選んだ場合、および対象が0人の場合は宿泊できない。 |
| TWN-216 | 連泊専用の操作は設けない。宿泊を繰り返すことは可能とする。 |

### 3.3 教会

| ID | 規則 |
| --- | --- |
| TWN-220 | 解毒の料金は1人につき10Gとする。 |
| TWN-221 | 蘇生の料金は1人につき `20 + 5×レベル` G とする。 |
| TWN-222 | 蘇生後のHPは最大値の50%（切り上げ）とする。SPは死亡時の値を維持する。 |
| TWN-223 | 治療の対象は複数選択できる。 |
| TWN-224 | 教会の利用でゲーム日数は進まない。 |

### 3.4 商店

| ID | 規則 |
| --- | --- |
| TWN-230 | 道具・武器・防具の購入と売却を行う。店の在庫は無制限とする。 |
| TWN-231 | 購入数、合計金額、所持品の空き枠を確定の前に表示する。 |
| TWN-233 | 装備中の品を直接売却できない。先に外す必要がある。 |
| TWN-234 | 素材と消耗品は数量を選んで売却できる。 |
| TWN-236 | 品揃えはA・B・Cの3段階とする。解禁条件は `data/shop_tiers.csv` の `ConditionDef` で判定する（DAT-2xx）。 |
| TWN-237 | 初期装備と店売り品は同一のIDを用いる。出自による売値の差を設けない。 |

### 3.5 酒場

| ID | 規則 |
| --- | --- |
| TWN-240 | クエストの受注、進行確認、報告を行う（QST-0xx, QST-3xx）。 |
| TWN-241 | 同時受注の上限を設けない。破棄と期限も設けない。 |

## 4. 救済（TWN-3xx）

宿屋と教会の双方に「救済を受ける」を表示する。

| ID | 規則 |
| --- | --- |
| TWN-300 | 全登録者について、通常サービスで現在の不足を解消するための合計料金 `C` を算出する。 |
| TWN-301 | 生存者のHPまたはSPに不足があれば、その者の宿泊料金を `C` に加える。 |
| TWN-302 | 生存者が毒状態であれば、解毒料金を `C` に加える。 |
| TWN-303 | 死亡者については、蘇生料金と、蘇生後の全回復に必要な宿泊料金の両方を `C` に加える。死亡者は毒状態を持たないため、解毒料金は加えない。 |
| TWN-304 | `C > 0` かつ `所持金 < C` の場合にのみ救済を利用できる。登録者が0人の場合、および全員が完全に回復している場合は利用できない。 |
| TWN-305 | 「所持金○Gをすべて渡して、登録者全員を回復します」の確認を表示する。 |
| TWN-306 | 確定すると所持金を0にし、全登録者の死亡と毒を解除し、HPとSPを満タンにする。 |
| TWN-307 | 救済でゲーム日数は進まない。 |
| TWN-308 | 救済に借金は発生しない。所持金が0であっても利用できる。 |
| TWN-309 | 救済は資金不足による進行不能の回避を目的とする。条件を満たすよう所持金を使い切る遊び方を禁止しない。 |

## 5. ゲーム日数（TWN-5xx）

| ID | 規則 |
| --- | --- |
| TWN-500 | ゲーム日数は整数とし、初期値を1とする。 |
| TWN-501 | 宿泊の取引が成立したときにのみ1進める。 |
| TWN-502 | 保存、ロード、現実の時刻の経過、歩行、戦闘、救済のいずれでも進めない。 |
| TWN-503 | 待機して日数だけを進める操作は設けない。 |
| TWN-504 | 起動時に現実の経過時間で日数を加算しない。 |
| TWN-505 | セーブファイルの保存時刻は、スロットの表示にのみ用いる。日数の判定に用いない。 |

## 6. ボスの復活（TWN-6xx）

| ID | 規則 |
| --- | --- |
| TWN-600 | 最終ボス以外のボスは、`最終撃破日 == null` または `現在日 - 最終撃破日 >= 30` のときに存在する。 |
| TWN-601 | 再撃破した時点で最終撃破日を更新する。 |
| TWN-602 | 初回撃破フラグは永久に保持する。復活によって通路の開放、商店の品揃え、クエストの解禁、魔法陣の起動を巻き戻さない。 |
| TWN-603 | 復活したボスは初回と同じ強さとし、経験値・お金・抽選ドロップを再取得できる。 |
| TWN-604 | 宝箱は補充しない。クエストの報酬と初回イベントの報酬は再取得できない。 |
| TWN-605 | 最終ボスはクリアフラグの成立後に復活しない。 |
| TWN-606 | 日数は期限ではなく、再出現の管理にのみ用いる。 |
| TWN-607 | DEPARTUREに、最終ボス以外のボスについて「未討伐」「再出現までN日」「再出現済み」のいずれかを表示する。 |

## 7. 意図的に許容する事象（TWN-7xx）

| ID | 事象 |
| --- | --- |
| TWN-700 | 冒険者の登録と初期装備の売却により、1人あたり2Gを繰り返し得られる。低利益であるため、登録の有料化と売却禁止のいずれも設けない。 |
| TWN-701 | 30泊してボスを再出現させることができる。ただし通常の宿泊料金を要する。 |
| TWN-702 | 僧侶が蘇生スキルを習得している場合、街での蘇生が無料で行えるため、教会の蘇生は主に僧侶の不在時・死亡時の保険として機能する。 |

これらを不具合として扱わない。変更する場合は設計変更として判断を仰ぐ。

## 8. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| F01 | 全員が満タンの状態で有料の宿泊を行う | 通常料金を支払い、日数が1進む。救済は利用できない | TWN-211, 213, 214, 304 |
| F02 | 救済料金 `C` に対し、所持金を `C-1` と `C` にして判定する | `C-1` では利用可、`C` では利用不可。救済で日数は変化しない | TWN-300〜304, 307 |
| F03 | 3日目に第1ボスを撃破し、32日目と33日目に再訪する | 32日目は不在、33日目は復活。魔法陣と初回撃破フラグは維持される | TWN-600, 602 |
| F04 | ボスを再撃破し、同じフロアの宝箱とクエストを確認する | ボスの報酬は再取得できる。宝箱とクエストの報酬は再取得できない | TWN-603, 604 |
| F05 | ruins_f2へ未到達／到達済み、第1ボス未撃破／撃破済みで商店を開く | 品揃えA・B・Cが解禁条件どおりに切り替わる | TWN-236 |
| F06 | 全員が満タンかつ登録者0人の状態で救済を試みる | いずれの場合も救済を利用できない | TWN-304 |
| F07 | ニューゲーム直後、登録者0人の状態で各施設・出発・セーブ・メニューを試みる | ギルドとタイトルへ戻る操作のみ選択できる。メニュー・セーブ・出発・他施設は選択できない。1人登録すると解除される | TWN-110〜112, FLW-110 |

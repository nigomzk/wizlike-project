# 冒険者・成長

冒険者の作成、編成、能力、経験値と成長、スキルの習得と使用を定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| ギルド・宿屋・教会の料金と操作 | `spec/20-town.md` |
| 装備の可否判定と所持品の容量 | `spec/35-inventory.md` |
| 戦闘中のスキルの解決 | `spec/50-battle.md` |
| 職業・スキルの数値 | `data/jobs.csv`, `data/skills.csv`, `data/skill_effects.csv` |
| 顔画像とポートレートの素材 | `tech/presentation.md` |

## 1. 登録と作成（PTY-0xx）

| ID | 規則 |
| --- | --- |
| PTY-000 | 登録は無料とする。登録者の上限を20人とする。 |
| PTY-001 | 同じ職業の冒険者を複数登録できる。 |
| PTY-002 | 作成時に名前、職業、顔画像を選ぶ。 |
| PTY-003 | 名前は前後の空白を除去したうえで1〜12文字とする。改行を含められない。 |
| PTY-004 | 同名の冒険者を登録できる。 |
| PTY-005 | 顔画像は10種から選ぶ。全職業で同じ10種を選択でき、能力に影響しない。 |
| PTY-006 | 作成を確定した時点で単調増加するIDを割り当て、登録者一覧へ追加する（GLS-403）。 |
| PTY-007 | 作成を途中でキャンセルした場合、所持金・装備・IDのいずれも消費しない。 |
| PTY-008 | 登録後も名前と顔画像を無料で変更できる。職業は変更できない。 |
| PTY-009 | 新規の登録者はレベル1とし、HPとSPを満タンにする。 |
| PTY-010 | 新規の登録者に、職業別の初期武器と布の服を装備済みで支給する。装飾品は支給しない。 |
| PTY-011 | 新規の登録者は初期スキルを習得済みとする。習得料金を要しない。 |
| PTY-012 | 登録者が20人のとき、21人目の作成を拒否する。所持金・装備・IDの状態をいずれも変更しない。 |

## 2. 編成と削除（PTY-1xx）

| ID | 規則 |
| --- | --- |
| PTY-100 | パーティの追加、外し、順序変更をギルドで行う。パーティの順序は意味を持つ（GLS-304）。 |
| PTY-101 | 同一の冒険者をパーティへ二重に登録しない。 |
| PTY-102 | 街ではパーティ0人を許容する。出発の条件はFLW-104に従う。 |
| PTY-103 | 冒険者の削除では、名前とレベルを示して確認する。 |
| PTY-104 | 削除した冒険者をパーティからも外す。 |
| PTY-105 | 削除した冒険者の装備を共有の所持品へ返す。返却によって30枠を超える場合は削除できない（INV-1xx）。 |
| PTY-106 | 削除した冒険者のIDを再利用しない。 |
| PTY-107 | 待機者のHP・SP・毒・死亡・装備・習得スキル・経験値をすべて保持する。編成の変更で回復しない。 |

## 3. 能力（PTY-2xx）

| ID | 能力 | 役割 |
| --- | --- | --- |
| PTY-200 | HP | 0になると死亡する（BTL-413）。 |
| PTY-201 | SP | スキルの消費資源。 |
| PTY-202 | STR | 攻撃力に加算する（BTL-003）。 |
| PTY-203 | VIT | 守備力に加算する（BTL-003）。 |
| PTY-204 | TEC | 物理命中、魔法の攻防、回復量に影響する。 |
| PTY-205 | AGI | 行動順と回避率に影響する。 |
| PTY-206 | LUC | 状態異常の付与成功率に影響する。 |

| ID | 規則 |
| --- | --- |
| PTY-210 | レベル1の基礎値は職業ごとに固定とし、乱数を用いない。 |
| PTY-211 | 装備による補正は基礎能力とは別に管理する。装備し直すたびに基礎能力へ加算して保存しない。 |
| PTY-212 | 職業ごとの役割は次のとおり。戦士は物理攻撃、騎士は防御とかばう、魔術師は属性攻撃、僧侶は回復と蘇生、斥候は高速行動と探索支援とする。 |

## 4. 経験値と成長（PTY-3xx）

| ID | 規則 |
| --- | --- |
| PTY-300 | 経験値は累積値で管理する。 |
| PTY-301 | レベル `L` に到達するのに必要な累積経験値は `20 × (L² - 1)` とする。 |
| PTY-302 | 次のレベルまでに追加で必要な経験値は `40 × L + 20` とする。 |
| PTY-303 | レベルの上限を20とする。レベル20の累積経験値を7980に固定する。上限を超えた分は破棄する。 |
| PTY-304 | 複数のレベルを跨いで経験値を得た場合、1レベルずつ順に成長抽選を行う。 |
| PTY-305 | 成長は能力ごとに独立して `固定増加値 + Bernoulli(職業別確率)` を加算する。HPとSPも同様に、追加分は0か1とする。 |
| PTY-306 | 成長の乱数は冒険者ごとの `growth_rng` を用いる（GLS-201）。同じセーブから同じ操作を行えば同じ成長結果になる。 |
| PTY-307 | `growth_rng` は各レベルにつき HP, SP, STR, VIT, TEC, AGI, LUC の順に引く。 |
| PTY-308 | レベルアップで増えた最大HPと最大SPの分だけ、現在のHPとSPを増やす。全回復はしない。 |
| PTY-309 | 基礎能力が低下することはない。 |
| PTY-310 | 成長の結果を一覧で表示し、まとめて閉じられるようにする。 |
| PTY-311 | 装備の着脱で成長を再抽選しない。 |
| PTY-312 | 戦闘勝利による経験値の配分はBTL-704〜706に、クエスト報告による配分はQST-4xxに従う。いずれの場合も、経験値を得たその場でレベルアップする。 |

## 5. スキル（PTY-4xx）

| ID | 規則 |
| --- | --- |
| PTY-400 | スキルは訓練場でお金を払って習得する。 |
| PTY-401 | 習得の可否は職業と必要レベルで決まる。前提スキルとスキルポイントは設けない。 |
| PTY-402 | 必要レベルを満たし、未習得であり、所持金が料金以上であれば習得できる。 |
| PTY-403 | 習得済みのスキルを再度習得できない。初期スキルは作成時点で習得済みとして扱い、重複を防ぐ。 |
| PTY-404 | スキルのランクアップと転職は設けない。 |
| PTY-405 | 各スキルは使用場面（`contexts`）を持つ。戦闘専用のスキルを街と探索で使用できない。 |
| PTY-406 | 探索中と街では、メニューから回復・解毒・蘇生のスキルと、対応するアイテムを使用できる。 |
| PTY-407 | 街と探索において、回復の対象が全員満タンであるなど効果を持たない場合、そのスキルを使用できない。 |
| PTY-408 | 解毒スキルは、毒状態でない対象を選択できない。 |

### 5.1 忍び足

| ID | 規則 |
| --- | --- |
| PTY-410 | `silent_steps` はパーティ共通の残り効果歩数を1つ持つ（GLS-309）。 |
| PTY-411 | 再使用すると残り効果歩数を20に上書きする。加算しない。 |
| PTY-412 | 使用者が死亡しても効果は残る。街へ戻ると解除する。 |
| PTY-413 | 通常の階層移動では効果が残る。 |
| PTY-414 | 歩行毒を防がない（DNG-1xx）。 |

## 6. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| G01 | 20人登録した状態で21人目の作成を試みる | 失敗する。所持金・装備・IDの状態をいずれも変更しない | PTY-000, 012 |
| G02 | 全5職業を1人ずつ作成する | 職業別の初期武器と布の服を装備し、初期スキルを習得し、初期能力が `data/jobs.csv` と一致する。装備は所持品枠に数えない | PTY-009〜011, INV-101 |
| G03 | 所持金が不足する状態で訓練を行い、所持品の枠が不足する状態で削除を行う | いずれも失敗し、どのデータも部分的に更新されない | PTY-402, 105, TWN-101 |
| L01 | 累積経験値を60、480、7980の境界に設定する | それぞれレベル2、5、20になる。複数レベルを順に処理し、上限の超過分を破棄する | PTY-301, 303, 304 |
| L02 | 成長の直前に保存し、成長させ、ロードして同じ操作を行う | 基礎能力の結果が一致する。装備の着脱で成長を再抽選しない | PTY-306, 307, 311 |
| L03 | 死亡者・待機者・レベル上限者を含む状態で報酬を配分する | 生存している参加者へ均等に配分する。死亡者と待機者へ配分しない。上限者の分は再配分しない | PTY-312, BTL-704〜706 |
| P01 | 名前に前後の空白、13文字、0文字を入力する | 空白を除去して1〜12文字の場合のみ受理する | PTY-003 |
| P02 | 忍び足を使用中に再使用し、街へ戻り、階層を移動する | 再使用で20へ上書きされ加算されない。街で解除され、階層移動では維持される | PTY-411〜413 |

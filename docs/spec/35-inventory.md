# 所持品・装備

パーティ共通の所持品、装備の枠と制限、容量判定を定義する。街・探索・戦闘のいずれからも参照される横断的な規則。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 商店の購入・売却の操作と価格表示 | `spec/20-town.md` |
| 冒険者の削除に伴う装備の返却 | `spec/30-party.md` |
| 戦闘ドロップの抽選、戦闘中のアイテム予約（BTL-107）、装飾品VITの守備力への反映（BTL-003） | `spec/50-battle.md` |
| クエストの納品と報酬 | `spec/60-quest.md` |
| 帰還の糸の使用条件 | `spec/40-dungeon.md`（DNG-701） |
| 装備・アイテムの数値 | `data/equipment.csv`, `data/items.csv` |

## 1. 容量（INV-1xx）

| ID | 規則 |
| --- | --- |
| INV-100 | 共有の所持品は30枠とする。パーティと待機者で共通とする。 |
| INV-101 | 装備中の品は所持品の枠に数えない。 |
| INV-102 | 武器・防具・装飾品は1個につき1枠を占める。 |
| INV-103 | 消耗品と素材は、同一IDごとに1枠あたり9個まで格納する。10個であれば2枠を占める。 |
| INV-104 | 同種の品を追加する際は、部分的に埋まっているスタックから先に詰める。 |
| INV-105 | 重要アイテムは別の辞書で管理し、30枠に数えない。売却と破棄のいずれもできない（SCP-319）。 |

---

## 2. 取得と破棄（INV-2xx）

| ID | 規則 |
| --- | --- |
| INV-200 | 所持品への追加・削除・交換は、差分を先に試算し、成功する場合にのみ適用する。 |
| INV-201 | 容量が不足する場合、取引の全体を成立させない。部分的な取得を行わない。 |
| INV-202 | アイテムの破棄では数量を確認する。 |
| INV-203 | 装備変更とアイテムの破棄は、街と探索のメニューで行える。 |
| INV-204 | 死亡している冒険者の装備も変更できる。 |
| INV-205 | 戦闘ドロップは一時獲得一覧に置き、空きへ入れる・既存の品を捨てる・獲得を諦める、のいずれかを選ばせる（BTL-711）。 |
| INV-206 | 宝箱は中身のすべてを受け取れる場合にのみ開封を確定する。容量が不足する場合は整理を案内し、未開封のまま戻す。部分的な取得を行わない。 |
| INV-207 | クエストの報告では、納品で減る品と報酬で増える品の両方を含めて容量を判定する。全報酬が入らない場合は報告できない（QST-3xx）。 |
| INV-208 | 商店では、容量が不足する場合に購入できない。 |

## 3. 装備（INV-3xx）

| ID | 規則 |
| --- | --- |
| INV-300 | 装備枠は武器・防具・装飾品の3つとする。 |
| INV-301 | 職業による装備制限を設ける。`data/equipment.csv` の `allowed_jobs` に含まれる職業のみが装備できる。 |
| INV-302 | 盾を独立した枠として扱わない。騎士の防御は防具とスキルで表現する。 |
| INV-303 | 装備変更では、外す品と着ける品の差分を計算して容量を判定する。交換できない場合は何も変更しない。 |
| INV-304 | 装備の変更で最大HPが下がった場合、現在HPを新しい最大HPへ丸める。 |
| INV-305 | 装備の変更で最大HPが上がった場合、現在HPを増やさない。最大SPについても同様とする。 |
| INV-306 | 武器を外した状態でも通常攻撃を行える。武器の攻撃力を0として計算する。 |
| INV-307 | 防具を外した状態では防御力の加算を0とする。 |
| INV-309 | 装備品の `stat_bonus` におけるHPとSPは、最大値への加算として扱う。 |
| INV-310 | 装備の比較では、ATK・DEF・能力値の差分を表示する。 |

## 4. アイテムの使用（INV-4xx）

| ID | 規則 |
| --- | --- |
| INV-400 | 各アイテムは使用場面（`contexts`）を持つ。 |
| INV-401 | 素材は戦闘とメニューのいずれでも使用できない。 |
| INV-402 | 回復とSP回復は最大値を超えない。既に満タンである対象には使用できない。 |
| INV-403 | アイテムによる回復量は `restore_flat` の値をそのまま用いる。使用者のTECを加算しない（スキルの回復式BTL-018とは異なる）。 |

## 5. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| I01 | 同一の消耗品を8個持つ状態で3個追加する | 9個の枠と2個の枠の計2枠になる | INV-103, 104 |
| I02 | 30枠が埋まった状態で装備を交換し、装備を取り外す | 差分で収まる交換は成立する。31枠目を要する取り外しは失敗する | INV-303, 101 |
| I03 | 所持品が満杯の状態で宝箱を開け、クエストを報告する | 開封・完了・料金・納品・経験値のいずれも進まない。整理後に一度だけ取得できる | INV-206, 207, 201 |
| I04 | 薬草2個を味方3人に予約する | 3人目を予約できない。キャンセルで枠が戻る | BTL-107 |
| I05 | 最大HPが下がる装備と上がる装備へ変更する | 下がる場合は現在HPを新上限へ丸める。上がる場合は現在HPを増やさない | INV-304, 305 |
| I06 | 職業が装備できない品を装備しようとする | 拒否し、装備と所持品のいずれも変更しない | INV-301 |
| I07 | 武器と防具を外した状態で戦闘を行う | 通常攻撃を行える。武器ATKと防具DEFを0として計算する | INV-306, 307 |

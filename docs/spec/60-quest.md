# クエスト

任意の討伐・納品クエストの状態、進捗、報告を定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 酒場の操作 | `spec/20-town.md`（TWN-240） |
| 報酬アイテムの容量判定 | `spec/35-inventory.md`（INV-207） |
| 経験値によるレベルアップと成長 | `spec/30-party.md`（PTY-3xx） |
| 討伐数の加算タイミング | `spec/50-battle.md`（BTL-709） |
| クエストの内容・必要数・報酬 | `data/quests.csv` |

---

## 1. 状態（QST-0xx）

| ID | 規則 |
| --- | --- |
| QST-000 | クエストの状態は LOCKED → AVAILABLE → ACTIVE → COMPLETED の順に遷移する。逆行しない。 |
| QST-001 | 解禁条件が成立した時点でAVAILABLEにする。 |
| QST-002 | 受注した時点でACTIVEにする。 |
| QST-003 | 酒場で報告した時点でCOMPLETEDにする。条件の達成だけでは自動的に報告しない。 |
| QST-004 | 各クエストは一度のみ完了できる。完了後に再受注できない。 |
| QST-005 | 解禁条件は `ConditionDef` で表す。種別は `always`、`floor_visited`、`boss_first_defeated`、`warp_unlocked` の4つとする（DAT-2xx）。 |
| QST-006 | 解禁条件が成立した際に小さな通知を表示する。 |

---

## 2. 進捗（QST-2xx）

| ID | 規則 |
| --- | --- |
| QST-200 | 討伐の進捗は、受注した後に発生した戦闘の勝利時にのみ加算する（BTL-709）。 |
| QST-201 | 討伐数は敵IDの完全一致で数える。別IDの敵を含めない。 |
| QST-202 | 加算は必要数を上限とする。上限を超えて蓄積しない。 |
| QST-203 | 逃走した戦闘と全滅した戦闘では進捗を加算しない。 |
| QST-204 | 納品は、受注より前から所持していた品も使用できる。 |
| QST-205 | 納品の達成判定は、報告の時点の在庫から算出する。固定のカウンターを保存しない。 |

---

## 3. 報告（QST-3xx）

| ID | 規則 |
| --- | --- |
| QST-300 | 報告は酒場でのみ行える。 |
| QST-301 | 報告には、生存しているパーティメンバーが1人以上いることを要する。 |
| QST-302 | 納品する品は報告の時点で消費する。 |
| QST-303 | 納品で減る品と報酬で増える品の両方を含めて容量を判定する。全報酬が入らない場合は報告できない（INV-207）。 |
| QST-304 | 納品、報酬の付与、完了フラグの設定を一括で確定する。条件が不足する場合は一切変更しない（TWN-101）。 |
| QST-305 | 報酬は経験値、お金、アイテムとする。 |

---

## 4. 経験値の配分（QST-4xx）

| ID | 規則 |
| --- | --- |
| QST-400 | 報酬の経験値は合計値として定義する。 |
| QST-401 | 報告の時点で生存しているパーティメンバーへ、戦闘と同じ方法で配分する（BTL-704〜706）。 |
| QST-402 | 待機者と死亡者には配分しない。 |
| QST-403 | クエストの経験値でもその場でレベルアップする（PTY-312）。 |
| QST-404 | 報告の後にパーティを変更しても再配分しない。 |
| QST-405 | 少人数で報告することで経験値を集中できる。これを仕様として許容する。 |

---

## 5. 表示（QST-5xx）

| ID | 規則 |
| --- | --- |
| QST-500 | 依頼文は、対象・必要数・用途を1〜2文で説明する。 |
| QST-501 | 必要数と報酬はUIで構造化して表示する。依頼文の中だけに記載しない。 |
| QST-502 | クエストの詳細に、合計経験値、現在のパーティ人数での1人あたり経験値、獲得G、報酬アイテムを明示する。 |

---

## 6. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| Q01 | 4種の解禁条件それぞれについて、成立前と成立後の状態を確認する | `always` は開始時から、`floor_visited` は該当フロアの訪問後、`boss_first_defeated` は初回撃破後、`warp_unlocked` は魔法陣の起動後にAVAILABLEになる | QST-001, 005 |
| Q02 | 受注前に対象の敵を倒し、受注後に倒す | 受注前の討伐は加算されない。受注後のみ加算される | QST-200 |
| Q03 | `wolf` の討伐クエストを受注し、`red_wolf` を倒す | 進捗は加算されない | QST-201 |
| Q04 | 必要数を超えて対象を倒す | 進捗は必要数で止まる | QST-202 |
| Q05 | 受注前から所持していた素材で納品を報告する | 報告できる | QST-204 |
| Q06 | 生存しているパーティメンバーが0人の状態で報告する | 報告できない。納品・報酬・完了フラグのいずれも変化しない | QST-301, 304 |
| Q07 | 報告後にパーティを変更する | 経験値は再配分されない | QST-404 |

# メニュー（MENU）・能力・スキル

TOWNとEXPLORATIONから開く。開いている間は日数・敵・遭遇残り歩数を進めない（FLW-201）。所持品・装備・地図はそれぞれの画面文書に置く。

---

## 1. 遷移

| 遷移元 | 遷移先 |
| --- | --- |
| TOWN（登録者1人以上）、EXPLORATION | 元のTOWNまたはEXPLORATION、SETTINGS、TITLE（FLW-013, FLW-110） |

---

## 2. 表示

| 項目 | 内容 | 根拠 |
| --- | --- | --- |
| 項目 | 所持品、装備、スキル、能力、地図、設定、タイトルへ | FLW-013 |
| 所持金 | 所持金ヘッダー | PRS-205 |
| 能力 | 冒険者ごとのレベル、累積経験値と次のレベルまでの経験値、HP/SP、装備補正を含む能力値、攻撃力・守備力、死亡と毒 | BTL-002, BTL-003, PTY-301, PTY-302 |
| スキル | 冒険者ごとの習得済みスキル、消費SP、使用場面 | PTY-405 |

---

## 3. 操作

| 操作 | 結果 | 選択できない条件 | 根拠 |
| --- | --- | --- | --- |
| 所持品 / 装備 / 地図 | 各画面を開く | なし | FLW-013 |
| スキルの使用 | 使用者と対象を選んで使用する | 現在の場面で使えないスキル、SP不足、効果のない対象（`INVALID_TARGET`） | PTY-405〜408 |
| 設定 | SETTINGSを開く | なし | FLW-111 |
| タイトルへ | 未保存の変更があれば `unsaved_warning` の確認を表示し、確定でTITLEへ戻る | なし | FLW-300, FLW-108 |
| 閉じる / Esc | 元の画面へ戻る | なし | PRS-104 |
| M（探索中） | 地図を直接開く | なし | PRS-106 |

---

## 4. 文言

`unsaved_warning`、`error_invalid_target`

なし。

## 6. 手動確認

| ID | 手順 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| U25 | 街と探索中にメニューを開き、能力とスキルを確認する。探索中に回復スキルを使い、満タンの対象を選ぼうとする | 能力値は装備補正込みで表示される。回復が反映される。満タンの対象は選べない。メニュー中に危険度が変化しない | FLW-201, PTY-405〜407, BTL-002 |
| U35 | 街でメニューを開いて能力を確認する。装備を変更して能力に戻る。設定を開いて戻る。閉じる / Escを押す | 所持金と能力が表示され、装備変更後の能力値が補正込みの値に変わる。設定から戻るとMENUに戻る。閉じるとTOWNに戻る | FLW-013, 110, 111, 113, BTL-002 |

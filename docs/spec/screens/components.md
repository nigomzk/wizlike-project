# 共通UI部品

各画面が利用する共通の部品を定義する。画面ごとに同等の実装を重複させない（ARC-207）。部品は、それを最初に使う画面の実装で作る。

---

## 1. 遷移

なし。各画面の内部で用いる。

---

## 2. 表示

| ID | 画面 | 構成 |
| --- | --- | --- |
| PRS-205 | 施設 | 共通の見出し・所持金・一覧・詳細・戻るを用いる（ARC-207） |

| 部品 | 内容 | 根拠 |
| --- | --- | --- |
| 確認ダイアログ | 確認文、確定で変更される項目と費用、「はい」「いいえ」。初期選択は「いいえ」 | FLW-203, TWN-102 |
| 一覧・詳細・戻る | 見出し、スクロール可能な一覧、選択中の項目の詳細、戻るボタン | PRS-205, PRS-007 |
| 所持金ヘッダー | 現在の所持金。施設画面とメニューの上部に置く | PRS-205 |
| フォーカス表示 | キーボードで選択中のボタン・項目を枠で示す | PRS-007 |
| 選択不可の表示 | 選べない項目を、色に加えて文字またはアイコンで示す | PRS-006, TWN-110 |
| エラー通知 | サービスの `error_code` を `data/texts.csv` の `error_*` で表示する | ARC-400〜402 |
| 通知 | 操作を妨げない短い表示を、そのとき表示している画面の上部に数秒間出す。クエストの解禁（QST-006）などに用いる | QST-006 |
| 冒険者の状態表示 | 顔、名前、HP/SP、死亡と毒。死亡と毒は文字またはアイコンを併記する | PRS-006 |

---

## 3. 操作

| 操作 | 結果 | 根拠 |
| --- | --- | --- |
| Enter / 左クリック | 決定 | PRS-104 |
| Esc / 戻るボタン | キャンセル、または1つ前へ戻る | PRS-104 |
| 矢印キー、Tab / Shift+Tab | フォーカスの移動 | PRS-107 |
| 確認ダイアログの表示中 | 背景の画面への入力を遮断する | FLW-200 |

## 6. 手動確認

| ID | 手順 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| U01 | 確認ダイアログを開き、何も選ばずにEnterを押す。再度開いてEscを押す。背景のボタンをクリックする | Enterで「いいえ」が実行される。Escで閉じる。背景のボタンは反応しない | FLW-200, 203 |
| U02 | 一覧・詳細・戻るを使う画面を、キーボードのみ、マウスのみでそれぞれ操作する | フォーカス枠が常に見える。長い一覧をスクロールできる。戻るで1つ前の画面へ戻る | PRS-007, 104, 107 |

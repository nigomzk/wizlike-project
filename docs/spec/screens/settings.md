# 設定（SETTINGS）

TITLEとMENUの両方から開く同一の画面（FLW-111）。進行中のセッションを参照しない（FLW-112）。

---

## 1. 遷移

| 遷移元 | 遷移先 |
| --- | --- |
| TITLE、MENU | 呼び出し元（FLW-113） |

---

## 2. 表示

| 項目 | 内容 | 根拠 |
| --- | --- | --- |
| マスター音量 | 0〜100。初期値70。スライダーで1刻み、左右キーで5ずつ増減する | PRS-400 |
| 音量の数値 | 現在のマスター音量を、スライダーの右に数字で表示する。スライダーの操作とキーの操作に合わせて、即時に更新する | PRS-400 |
| フルスクリーン | ON / OFF。初期値OFF | PRS-400, PRS-001 |
| 戻る | 呼び出し元へ戻る | FLW-014 |

開いた場所によって項目を変えない（FLW-111）。

---

## 3. 操作

| 操作 | 結果 | 根拠 |
| --- | --- | --- |
| 音量の変更 | 即時に反映し、`user://settings.cfg` へ保存する。未保存フラグを立てない | PRS-401, PRS-405, FLW-301 |
| フルスクリーンの切替 | 即時に反映し、保存する | PRS-401, PRS-001 |
| F11 | どの画面でもフルスクリーンを切り替え、設定に保存する | PRS-108 |
| 戻る / Esc | 呼び出し元へ戻る | FLW-113, PRS-104 |

## 6. 手動確認

| ID | 手順 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| U05 | TITLEから設定を開き、音量とフルスクリーンを変更してアプリを再起動する。続いてF11を押す | 変更が即時に反映され、再起動後も保持される。音量の数値は、スライダーの位置と常に一致し、操作に合わせて即時に更新される。F11で切り替わり、その状態も保持される | PRS-400, 401, 108 |
| U06 | TITLEから設定を開いて戻る。MENUから設定を開いて戻る | それぞれ呼び出し元へ戻る。どちらから開いても項目と値が同じ | FLW-111, 113 |

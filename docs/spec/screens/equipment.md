# 装備

MENUから開く。

---

## 1. 遷移

| 遷移元 | 遷移先 |
| --- | --- |
| MENU | MENU |

---

## 2. 表示

| 項目 | 内容 | 根拠 |
| --- | --- | --- |
| 冒険者 | 対象の冒険者。死亡者も選べる | INV-204 |
| 装備枠 | 武器・防具・装飾品の現在の装備 | INV-300 |
| 候補 | 所持品のうち、その職業が装備できる品 | INV-301 |

| ID | 規則 |
| --- | --- |
| PRS-207 | 装備の候補を選んでいる間、ATK・DEF・能力値の変化を差分として表示する（INV-310）。 |

---

## 3. 操作

| 操作 | 結果 | 失敗の条件（エラー） | 根拠 |
| --- | --- | --- | --- |
| 装備する | 候補を選んで交換する | 交換で容量が不足する（`NO_SPACE`） | INV-303 |
| 外す | 所持品へ戻す | 容量が不足する（`NO_SPACE`） | INV-101, INV-303 |

---

## 4. 文言

`error_no_space`

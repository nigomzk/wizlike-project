# 探索（EXPLORATION / EVENT）

3D視界での移動と、足元・正面のイベントの確認を扱う。移動とイベントの規則はDNG-xxx、3Dの生成はMAP-3xxに従う。

---

## 1. 遷移

| 遷移元 | 遷移先 |
| --- | --- |
| DEPARTURE、BATTLE（逃走成功）、REWARD、EVENT、MENU | MENU、EVENT、BATTLE、TOWN、別フロア（FLW-007, FLW-008） |

---

## 2. 表示

| ID | 画面 | 構成 |
| --- | --- | --- |
| PRS-200 | 探索 | 左から中央に3D視界、右上240×240pxにミニマップ、上部に階層名と危険度、下部にパーティ4枠（顔・名前・HP/SP・死亡と毒）、右下に操作ボタン |
| PRS-201 | 探索（少人数） | 1〜3人編成では残りの枠を空き枠として明示する。探索中のパーティが0人になることはない（FLW-110） |

| 項目 | 内容 | 根拠 |
| --- | --- | --- |
| ミニマップ | 現在フロアの発見記録。北固定、現在位置と向き | DNG-4xx |
| 危険度 | 遭遇残り歩数の3段階を色と文字で示す。青「安全」、黄「注意」、赤「危険」。数値は表示しない | DNG-306, PRS-006 |
| 操作ボタン | 前進・後退・左右移動・左右旋回・調べる・メニュー | PRS-111, PRS-103, PRS-105 |

## 3. 操作

| 操作 | キー・ボタン | 結果 | 根拠 |
| --- | --- | --- | --- |
| 移動 | W / S / A / D、操作ボタン | 1セル移動する。演出は0.15秒 | DNG-002, PRS-100, PRS-101, PRS-500 |
| 旋回 | Q / E、操作ボタン | 90度旋回する。演出は0.12秒 | DNG-004, PRS-102, PRS-500 |
| 長押し | 移動・旋回キー | 演出の完了後に0.12秒間隔で繰り返す | PRS-501, DNG-007 |
| 調べる | F、「調べる」ボタン | 正面の宝箱・扉・近道・会話碑を操作する。足元の階段等の確認を再表示する | DNG-500, DNG-506 |
| メニュー | Esc、メニューボタン | MENUを開く | PRS-105 |
| 地図 | M | 地図を開く | PRS-106 |

### 3.1 イベントの確認（EVENT）

| 対象 | 表示 | 根拠 |
| --- | --- | --- |
| 階段・街出口・接続点 | 移動の確認。「いいえ」でそのセルに留まる | DNG-505〜507 |
| 宝箱 | 中身の表示。容量不足の場合は整理を案内し、未開封のまま戻す | INV-206 |
| 会話碑 | `insc_*` の文章 | DNG-508 |
| ボス | 予告文（`boss_*_pre`）の後に戦闘 | DNG-600 |
| 魔法陣 | 未起動は起動の確認。起動後は「街へ戻る」「留まる」 | DNG-706〜709 |

## 6. 手動確認

| ID | 手順 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| U29 | キーボードとマウスの操作ボタンで、移動・旋回・壁への衝突・長押しを行う | 視点がずれない。演出中の追加入力で二重に動かない。長押しで一定間隔で進む | DNG-002〜008, PRS-500, 501, W04 |
| U30 | 数歩進み、ミニマップと危険度を観察する。1〜3人編成で出発する | 歩いた場所と周囲の壁だけが記録される。危険度が色と文字で示される。空き枠が明示される | DNG-306, 402, PRS-200, 201 |
| U31 | 扉・近道・宝箱・会話碑を調べ、階段で移動する | それぞれの確認と文章が表示される。「いいえ」で留まり、到着直後に確認が繰り返されない | DNG-500〜508 |

# 探索

ダンジョン内の移動、歩数、イベント、遭遇、ミニマップ、帰還を定義する。

**この文書が扱わない範囲**

## 1. 移動（DNG-0xx）

| ID | 規則 |
| --- | --- |
| DNG-000 | 論理位置は整数のセル座標 `(x, y)` で表す。範囲は各軸0〜29とする。 |
| DNG-001 | 向きは 北0・東1・南2・西3 の整数で表す（GLS-310）。 |
| DNG-002 | 前進・後退・左平行移動・右平行移動はいずれも1セル移動する。 |
| DNG-003 | 左右の平行移動では向きを変えない。 |
| DNG-004 | 旋回は90度単位とする。自由移動と自由視点は設けない。 |
| DNG-005 | 壁、未開の扉、未開通の近道、範囲外のセルへは移動できない。 |
| DNG-006 | 移動と旋回の演出中は、追加の入力を保持しない。演出の完了時に次の入力を受け付ける。 |
| DNG-007 | キーの長押しは、演出の完了後に一定間隔で繰り返す。 |
| DNG-008 | 演出が中断された場合も、描画位置を論理位置に一致させる。 |
| DNG-009 | 移動の可否は制作用マップから生成した `FloorGrid` で判定する。物理エンジンによる滑りと押し戻しを移動仕様に用いない（MAP-3xx）。 |

## 2. 歩数と一歩の処理（DNG-1xx）

| ID | 規則 |
| --- | --- |
| DNG-100 | 前後・左右の成功した移動を、いずれも同じ1歩として数える。 |
| DNG-101 | 壁への衝突、旋回、調べる、メニューの開閉、扉の開閉では歩数を進めない。 |
| DNG-102 | 街からの出発、階段による到着、逃走による位置の復元は歩数に数えない。 |

一歩の処理順（DNG-110〜DNG-114）。この順序を入れ替えない。

| ID | 手順 |
| --- | --- |
| DNG-110 | 入力が可能であること、移動先が通行可能であることを検証する。 |
| DNG-111 | 論理セルを移し、移動の演出を行う。続いて歩行毒を処理する（DNG-120）。 |
| DNG-112 | 現在セルの踏破と、隣接する壁を記録する（DNG-4xx）。忍び足の残り効果歩数が1以上であれば1減らす。 |
| DNG-113 | 足元のイベント（階段・街出口・魔法陣・接続点・ボス）があれば優先して処理する。この歩では遭遇残り歩数を減らさない。 |
| DNG-114 | 足元のイベントがなければ遭遇残り歩数を1減らす。ただし、この歩で忍び足の効果が有効であった場合は減らさない。0に達した場合は通常戦を開始する。 |

### 2.1 歩行毒

| ID | 規則 |
| --- | --- |
| DNG-120 | 毒状態の生存者ごとに `max(1, floor(最大HP × 0.02))` のダメージを与える。 |
| DNG-121 | 歩行毒によってHPが1を下回らない。歩行毒で死亡しない。 |
| DNG-122 | 床・階段・魔法陣・ボス床のいずれへの侵入でも歩行毒を処理する。 |
| DNG-123 | 忍び足は歩行毒を防がない（PTY-414）。 |
| DNG-124 | 戦闘中の毒は別式とする（BTL-410）。 |

## 3. 遭遇（DNG-3xx）

| ID | 規則 |
| --- | --- |
| DNG-300 | 遭遇残り歩数を、一様整数 `12〜20` から抽選する。 |
| DNG-301 | 抽選を行うのは、街から出発したとき、戦闘に勝利したとき、逃走に成功したときの3つとする。 |
| DNG-302 | 階層の移動、ダンジョン間の移動、イベントの確認を断る操作では再抽選しない。 |
| DNG-303 | 特殊セル上での移動によって遭遇を回避できることを許容する。 |
| DNG-304 | 通常戦の出現編成は、そのフロアの3編成から等確率で抽選する。 |
| DNG-305 | 先制攻撃と不意打ちは設けない。 |
| DNG-306 | 危険度の表示は、遭遇残り歩数が9以上を青、5〜8を黄、1〜4を赤とする。正確な数値を画面に表示しない。 |
| DNG-307 | 遭遇の抽選には `encounter` 系列の乱数を用いる（GLS-202）。 |

## 4. ミニマップ（DNG-4xx）

| ID | 規則 |
| --- | --- |
| DNG-400 | 現在フロアの30×30全体を北固定で表示する。現在位置と向きを矢印で示す。 |
| DNG-401 | 未踏破の床を黒で表示する。 |
| DNG-402 | 発見記録に追加するのは、現在セルと、その東西南北に隣接する壁および調べる対象のみとする。 |
| DNG-403 | 未踏破の隣接する床を開示しない。 |
| DNG-404 | 階段・魔法陣・ボス床は、そのセルを踏んだ時点で記録する。 |
| DNG-405 | 扉・宝箱・近道・会話碑は、隣接した時点で記録する。 |
| DNG-406 | 地図メニューでは訪問済みのフロアを切り替えられる。凡例と、開封・開通の状態を表示する。 |
| DNG-407 | 手描き、注釈、地図からの移動のいずれも設けない。 |
| DNG-408 | 発見記録はセーブに含める。未保存の探索記録は全滅とロードで失われる。 |

## 5. イベント（DNG-5xx）

| ID | 規則 |
| --- | --- |
| DNG-500 | 宝箱・扉・近道・会話碑は、正面のセルに対する「調べる」で操作する。 |
| DNG-501 | 宝箱と会話碑のセルには進入できない。隣接するセルから調べる。 |
| DNG-502 | 通常の扉は両側から調べて開けられる。一度開けたら閉じる操作を要しない。開いた状態を永続的に保存する。 |
| DNG-503 | 近道は指定された側から調べたときにのみ初回の開通を行う。開通後は双方向に通行できる。 |
| DNG-504 | 通常の扉と近道は、開通後に通行可能なセルとして扱う。 |
| DNG-505 | 階段・街出口・接続点のセルに乗ると移動の確認を表示する。「いいえ」を選ぶとそのセルに留まる。 |
| DNG-506 | 同じセルに留まっている間は確認を再表示しない。「調べる」で再度確認できる。 |
| DNG-507 | 階段等で到着した直後は、足元のイベントを再発火させない。 |
| DNG-508 | 会話碑は何度でも読める。アイテムとフラグの報酬を持たない。 |
| DNG-509 | 床1セルにつきイベントを1個までとする（MAP-1xx）。 |

## 6. ボス（DNG-6xx）

| ID | 規則 |
| --- | --- |
| DNG-600 | ボスのいるセルへ進入すると予告文を表示し、戦闘を開始する。進入後の取り消しはできない。 |
| DNG-601 | 撃破したボスのセルは通行可能になる。 |
| DNG-602 | 第1ボスの奥から次のダンジョンへ移動できる。逆方向にも戻れる。 |
| DNG-603 | 復活したボスのセルへ徒歩で進入すると再戦する（TWN-600）。 |
| DNG-604 | 起動済みの魔法陣を使って街から第2ダンジョンへ移動する場合、復活したボスと戦わない。 |
| DNG-605 | 最終ボスに勝利した場合はFLW-4xxへ進む。最終ボスの奥のセルに重要な報酬を配置しない。 |

## 7. 帰還と魔法陣（DNG-7xx）

| ID | 規則 |
| --- | --- |
| DNG-700 | 第1ダンジョン1Fの街出口と、帰還の糸は、いずれも街へ戻す。 |
| DNG-701 | 帰還の糸は探索中のみ使用できる。確認をキャンセルした場合は消費しない。 |
| DNG-702 | 帰還時のHP・SP・毒・死亡をそのまま維持する。 |
| DNG-703 | 帰還時に忍び足の効果を解除する（PTY-412）。 |
| DNG-704 | 第1ダンジョンに中間地点を設けない。 |
| DNG-705 | 第2ダンジョン1Fの入口付近に魔法陣を1か所設ける。 |
| DNG-706 | 未起動の魔法陣に乗ると起動するかの確認を表示する。拒否した場合は未起動のまま留まり、再訪または「調べる」で再確認する。 |
| DNG-707 | 起動を承諾した時点で永久に解禁し、街の出発先へ追加する。続けて「街へ戻る」「留まる」を選ばせる。 |
| DNG-708 | 起動後も魔法陣に乗ると帰還の確認を表示する。 |
| DNG-709 | 街から魔法陣へ到着した直後は、帰還の確認を自動表示しない。 |
| DNG-710 | 魔法陣の起動と街との往復は無料とし、回数の制限を設けない。 |

## 8. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| E01 | 壁へ衝突し、旋回し、横移動する | 衝突と旋回は0歩、成功した横移動は1歩。論理座標と描画が一致する | DNG-100, 101, 008 |
| E02 | HPが1の毒状態の冒険者で1歩移動する | HPは1のまま。ゲームオーバーにならない | DNG-121 |
| E03 | 遭遇残り歩数が1の状態で階段のセルへ入る | 階段イベントが優先され、ランダム戦は発生しない。残り歩数1を維持する | DNG-113 |
| E04 | 未起動の魔法陣で拒否し、再訪して起動する | 拒否中は街から選択できない。起動後は選択できる。到着直後に帰還の確認が繰り返されない | DNG-706, 707, 709 |
| E05 | 忍び足を使用し、通常床を21歩移動する | 最初の20歩は遭遇残り歩数が減らず、21歩目から通常どおり減る。歩行毒は毎歩処理される | DNG-112, 114, 123 |
| E06 | 通路の突き当たりで前後左右を確認する | 現在セルと東西南北の壁・調べる対象のみが記録され、未踏破の隣接床は開示されない | DNG-402, 403 |
| E07 | 近道を許可されていない側から調べる。開通後に両側から通る | 許可側からのみ開通する。開通後は双方向に通行できる | DNG-503 |
| E08 | 階段で到着した直後に入力を行わず待つ | 足元のイベントが再発火せず、移動の確認が繰り返されない | DNG-507 |

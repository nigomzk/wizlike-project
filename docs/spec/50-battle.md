## 1. 規則

### 1.1 数値と計算（BTL-0xx）

| ID | 規則 |
| --- | --- |
| BTL-002 | 画面に表示する能力値は装備補正を含めた値とする。 |
| BTL-003 | 味方の攻撃力は `STR + 武器の攻撃力`、守備力は `VIT + 防具の防御力` とする。装飾品によるVIT補正は、守備力を求める前にVITへ加算する。 |
| BTL-004 | 敵は定義された攻撃力・守備力をそのまま用いる。敵はSTR/VITを持たない。 |
| BTL-005 | TECは魔法の攻撃・防御と物理命中の算出に用いる。 |

計算式（BTL-010〜BTL-019）。記法は `spec/00-glossary.md` に従う。

| ID | 対象 | 式 |
| --- | --- | --- |
| BTL-010 | 物理命中率 | `clamp(0.90 + 0.005×(攻撃側TEC - 対象AGI), 0.60, 0.98)` |
| BTL-011 | 睡眠中の対象への物理命中率 | `1.0`（BTL-010を上書きする） |
| BTL-012 | 魔法・回復の命中 | 常に成功とする。状態異常の付与のみBTL-016で別に判定する。 |
| BTL-013 | 通常攻撃の物理基礎値 | `max(1, 2×攻撃力 - 守備力)` |
| BTL-014 | 物理スキルの基礎値 | `BTL-013の値 × スキル倍率` |
| BTL-015 | 魔法の基礎値 | `max(1, スキル威力 + 2×攻撃側TEC - 対象TEC)` |
| BTL-016 | 状態異常の付与成功率 | `clamp(基礎成功率 + 0.005×(攻撃側LUC - 対象LUC), 0.05, 0.95) × 対象の当該異常耐性倍率` |
| BTL-017 | 最終ダメージ | `max(1, floor(基礎値 × 属性倍率 × 防御倍率 × かばう倍率 × r))`。`r` は一様整数 `90〜110` を100で割った値。 |
| BTL-018 | スキルの回復量 | `スキル威力 + 2×使用者TEC`。乱数を用いず、対象の最大HPを上限とする。アイテムの回復量は別規則とする（INV-403）。 |
| BTL-019 | 行動速度 | `AGI + 一様整数(0, 5)` |

| ID | 規則 |
| --- | --- |
| BTL-020 | 属性倍率は通常1.0、弱点1.5、耐性0.5とする。物理耐性も同じ倍率体系を用いる。 |
| BTL-022 | 防御コマンドによる防御倍率は0.5とする。 |
| BTL-023 | かばうによる倍率は0.7とする。 |
| BTL-024 | 持続毒によるダメージには、属性倍率・防御倍率・かばう倍率・乱数 `r` のいずれも適用しない。 |
| BTL-025 | 敵と味方の計算入力は共通の `BattleActor` に正規化し、陣営ごとに異なる計算式を定義しない。 |

### 1.2 ターンの進行と入力（BTL-1xx）

| ID | 規則 |
| --- | --- |
| BTL-100 | ターン開始時に、そのターン限定の防御状態とかばう状態を解除する。 |
| BTL-101 | 入力はパーティ順に、生存している味方に対して行う。死亡している味方は入力対象に含めない。 |
| BTL-102 | 睡眠中の味方にもコマンドを予約できる。実行時点でなお睡眠中であれば不発とする（BTL-202）。 |
| BTL-103 | 各味方に「攻撃」「スキル」「防御」「アイテム」のいずれかを割り当てる。 |
| BTL-104 | 全員の入力後に「実行」「選び直す」を提示する。「選び直す」は乱数を消費しない。 |
| BTL-105 | 逃走はパーティ共通の操作として、通常戦の入力画面から選択する。個別コマンドとは別扱いとする（BTL-5xx）。 |
| BTL-106 | SPが不足するスキルは入力の時点で選択不可とする。 |
| BTL-107 | 同一ターン内で予約できるアイテムは在庫数量までとする。入力を戻すと予約を解除し、複数の味方が同一在庫を取り合わない。 |
| BTL-108 | 戦闘中は装備変更、パーティ編成、セーブ、探索メニューを利用できない。 |
| BTL-109 | 実行確定後は、そのターンの入力を受け付けない。 |

ターン解決の順序（BTL-110〜BTL-115）。

| ID | 規則 |
| --- | --- |
| BTL-110 | 実行確定時に、各敵の行動を決定する（BTL-600, BTL-601）。 |
| BTL-111 | 続いて、敵の単体対象を抽選する（BTL-602）。 |
| BTL-112 | 続いて、生存している敵味方の全員に対して行動速度を1回ずつ抽選する（BTL-019）。抽選は味方を先、敵を後に行う。 |
| BTL-113 | 行動を優先群（priority=100）と通常群（priority=0）に分ける。防御とかばうを優先群、それ以外を通常群とする。 |
| BTL-114 | 各群の内部を行動速度の降順に並べ、優先群、通常群の順に実行する。 |
| BTL-115 | 行動速度が同じ場合は、味方を先、敵を後とする。味方どうしはパーティ順、敵どうしは出現順とする。 |

### 1.3 行動の実行（BTL-2xx）

| ID | 規則 |
| --- | --- |
| BTL-200 | 実行時点で行動者が死亡していれば、その行動を飛ばす。 |
| BTL-201 | 行動不能の判定は、死亡、睡眠、麻痺の順に評価する。 |
| BTL-202 | 行動者が睡眠中であれば行動できない。 |
| BTL-203 | 行動者が麻痺していれば、25%の確率で行動を失う。 |
| BTL-204 | 行動できる場合にのみ、対象の有効性と消費資源を再検証したうえで、SPまたはアイテムを消費して実行する。 |
| BTL-205 | 実行前の行動不能、および対象が無効であることによる不発では、SPもアイテムも消費しない。 |
| BTL-206 | 攻撃が命中しなかった場合、および状態異常の付与に失敗した場合は、消費が発生したものとして扱う。 |
| BTL-207 | 単体攻撃の予約対象が実行時に死亡していれば、生存している敵の出現順で先頭へ対象を変更する。 |
| BTL-208 | 味方を対象とする回復・蘇生等は対象を自動変更しない。対象が死亡している、蘇生対象が生存しているなど対象が無効であれば、不発とし消費しない。 |
| BTL-209 | 全体攻撃は、実行時点で生存している対象を出現順に列挙して処理する。 |
| BTL-210 | 回復・SP回復の対象が実行時点で既に最大値に達していた場合は、不発とし消費しない。 |
| BTL-211 | 1つの行動が複数の効果を持つ場合、効果は定義された配列順に適用する。 |
| BTL-212 | `requires_previous_hit` が真の効果は、直前の効果が命中している場合にのみ適用する。ダメージが成立しなかった場合、および対象がそのダメージで死亡した場合は、後続の状態異常を付与しない。 |

### 1.4 防御とかばう（BTL-3xx）

| ID | 規則 |
| --- | --- |
| BTL-300 | 防御は、その行動が実行された時点から当該ターンの末尾まで有効とする。 |
| BTL-301 | かばうは、指定した味方1人が受ける単体のダメージ攻撃を、かばう側（騎士）へ移し替える。 |
| BTL-302 | 移し替えたダメージは、騎士の守備力と耐性を用いて算出し、BTL-023の倍率を適用する。 |
| BTL-303 | かばうは全体攻撃、毒の継続ダメージ、回復には作用しない。 |
| BTL-304 | 移し替えた攻撃に付随する状態異常は、騎士が受ける。 |
| BTL-305 | 騎士が死亡、睡眠、麻痺のいずれかになった場合、かばうを停止する。これは麻痺による行動失敗の抽選（BTL-203）とは独立に評価する。 |
| BTL-306 | 複数の騎士が同一の味方をかばっている場合、パーティ順が先の有効な騎士1人のみが作用する。 |
| BTL-307 | かばうは連鎖しない。かばっている騎士を、別の騎士がかばうことはできない。 |
| BTL-308 | かばうの対象に自分自身を選択できない。 |

### 1.5 状態異常と死亡（BTL-4xx）

| ID | 規則 |
| --- | --- |
| BTL-400 | 毒・麻痺・睡眠は同時に併存しうる。 |
| BTL-401 | 同一の状態異常を重ねて付与した場合、効果の強度は増やさず、残り期間を長いほうへ更新する。 |
| BTL-402 | 状態異常のみを与えるスキル・行動は、命中判定を行わず、付与確率（BTL-016）のみを判定する。 |
| BTL-403 | ダメージに付随する状態異常は、ダメージが命中したあとに判定する（BTL-212）。 |

各状態の効果（BTL-410〜BTL-413）。

| ID | 状態 | 効果と解除 |
| --- | --- | --- |
| BTL-410 | 毒 | ターン末に最大HPの5%（切り上げ、最低1）を失う。戦闘中はこれにより死亡しうる。自然解除しない。解毒薬、解毒スキル、教会、死亡により解除する。探索中の歩行時ダメージは別式（DNG-1xx）。 |
| BTL-411 | 麻痺 | 行動の直前に25%で行動を失う。付与されたターンを含め、3回のターン末処理を経て解除する。戦闘終了時にも解除する。 |
| BTL-412 | 睡眠 | 行動できない。付与されたターンを含め、2回のターン末処理を経て解除する。正のダメージを直接受けた直後に解除する。毒の継続ダメージでは解除しない。戦闘終了時にも解除する。 |
| BTL-413 | 死亡 | HPが0の状態。すべての状態異常、防御、かばうを解除する。SPは保持する。通常の回復では解除できず、蘇生によってのみ解除する。 |

ターン末処理（BTL-420〜BTL-423）。

| ID | 規則 |
| --- | --- |
| BTL-420 | 生存している全員の毒ダメージを同時に適用する。 |
| BTL-421 | 続いて全滅を判定する。両陣営が同時に全滅した場合は、ゲームオーバーを優先する。 |
| BTL-422 | 両陣営に生存者が残っていれば、麻痺と睡眠の残り回数を1減らす。 |
| BTL-423 | 残り回数の減算は、その状態異常が付与されたターンの末尾から開始する。 |

### 1.6 逃走（BTL-5xx）

| ID | 規則 |
| --- | --- |
| BTL-500 | 逃走は通常戦でのみ選択できる。ボス戦では選択不可として表示する。 |
| BTL-501 | 逃走を選択すると、味方の個別コマンドをすべて破棄する。 |
| BTL-502 | 逃走の判定は、敵の行動より前に1回だけ行う。行動速度の並び（BTL-114）には参加しない。 |
| BTL-503 | 睡眠中・麻痺中であっても、生存していれば逃走判定に参加する。 |
| BTL-504 | 成功率は `clamp(0.60 + 0.01×(生存味方の平均AGI - 生存敵の平均AGI), 0.20, 0.95)` とする。 |
| BTL-505 | 成功時は経験値・お金・ドロップのいずれも得られない。その戦闘中に倒した敵の分も含めて報酬は発生しない。 |
| BTL-507 | 成功時は遭遇したセルで探索を再開し、遭遇残り歩数を再抽選する（DNG-3xx）。 |
| BTL-508 | 失敗時は味方は誰も行動せず、敵全員が通常の速度順で行動したのちターン末処理へ進む。 |
| BTL-509 | 失敗時に防御状態は付与しない。 |

### 1.7 敵（BTL-6xx）

| ID | 規則 |
| --- | --- |
| BTL-600 | 行動が重み付きで定義された敵は、相対重みに従って行動を1つ抽選する。重みの合計は100とする。 |
| BTL-601 | 行動が固定巡回で定義された敵は、ターン番号に対応する行動を決定的に選ぶ。選択に乱数を用いない。 |
| BTL-602 | 敵の単体対象は、ターン解決の開始時（実行確定の直後、BTL-111）に、生存している味方から等確率で抽選する。 |
| BTL-603 | 抽選した対象がその行動の実行時点で死亡していれば、生存している味方のパーティ順で先頭へ変更する。 |
| BTL-604 | 敵の全体対象は、実行時点で生存している味方を列挙して決定する。 |
| BTL-605 | 敵はSPを消費しない。 |
| BTL-606 | 敵には成長、装備、レベルアップを適用しない。 |
| BTL-607 | 定義に記載のない属性倍率および状態異常耐性倍率は1.0として扱う。 |
| BTL-608 | 敵が状態異常によって行動できなかった場合でも、固定巡回のターン番号は進める。 |
| BTL-609 | ボスに増援、形態変化、HPに応じた行動変化は設けない。 |
| BTL-610 | 1回の戦闘に出現する敵は最大3体とする。 |
| BTL-611 | 敵の行動のうち、効果を持たず表示のみを行うもの（`focus`）は、能力変化を一切伴わない。次の行動を予告する演出としてのみ機能する。 |

敵、敵行動、固定巡回の具体的な数値と並びは `data/enemies.csv`、`data/enemy_modifiers.csv`、`data/enemy_actions.csv`、`data/enemy_action_effects.csv`、`data/enemy_action_weights.csv`、`data/enemy_action_cycles.csv` を唯一の正とする。本文書に数値表を複写しない。

### 1.8 勝敗と報酬（BTL-7xx）

| ID | 規則 |
| --- | --- |
| BTL-700 | 各行動の直後に、勝利と全滅を判定する。 |
| BTL-701 | 敵が全滅した時点で即座に勝利とする。当該ターンのターン末処理を行わないため、毒による追加ダメージは発生しない。 |
| BTL-702 | 味方が全滅した時点で即座にゲームオーバーとする。 |
| BTL-703 | 勝利時、全敵の経験値と獲得Gをそれぞれ合計する。 |
| BTL-704 | 経験値は、生存している戦闘参加者 `N` 人へ `floor(合計EXP / N)` を配分する。余りは破棄する。 |
| BTL-705 | レベル上限に達している者も配分人数 `N` に含める。その者の受取分は破棄し、他の参加者へ再配分しない。 |
| BTL-706 | 死亡している参加者および待機中の登録者には経験値を配分しない。 |
| BTL-707 | 獲得Gはパーティ共有の所持金へ加算する。 |
| BTL-708 | ドロップは敵の個体ごとに1回抽選する。1体から複数種類は落とさない。種別と個数は固定とする。 |
| BTL-709 | 勝利確定時に、受注中の討伐クエストについて対象の敵数を必要数を上限として加算する（QST-2xx）。逃走時および全滅時は加算しない。 |
| BTL-710 | 報酬画面では、経験値と獲得Gを先に確定する。 |
| BTL-711 | ドロップ品は一時獲得一覧に置き、所持品の空きへ入れる、既存の品を捨てる、獲得を諦める、のいずれかを選ばせる（INV-2xx）。 |
| BTL-712 | 報酬画面を閉じる前に、未処理のドロップ品について破棄の確認を行う。 |
| BTL-713 | 報酬画面を再度開いても、同じ戦闘の報酬を二重に取得できない。 |

### 1.9 乱数の使用（BTL-8xx）

| ID | 規則 |
| --- | --- |
| BTL-800 | `battle` 系列の乱数は次の順序で引く。敵の行動選択 → 敵の単体対象 → 味方の行動速度 → 敵の行動速度 → 実行順に、行動不能判定 → 命中判定 → ダメージ倍率 → 状態異常判定。 |
| BTL-802 | 命中しなかった場合、ダメージ倍率および付随する状態異常の乱数を引かない。 |
| BTL-803 | 固定巡回による敵の行動選択では乱数を引かない（BTL-601）。 |
| BTL-804 | ドロップは `loot` 系列を用い、勝利時に敵の出現順で抽選する。ドロップ率100%の場合は抽選を行わず確定させる。 |

### 1.10 状態の反映（BTL-9xx）

| ID | 規則 |
| --- | --- |
| BTL-900 | 戦闘中の味方の値は `BattleSession` 上でのみ更新する。`CharacterState` を同時に書き換えない。 |
| BTL-901 | 戦闘終了時に、生存・死亡・毒・HP・SPを `CharacterState` へ一度だけ同期する。 |
| BTL-902 | 経験値の配分と成長処理は、BTL-901の同期が完了したあとに実行する。 |
| BTL-903 | 戦闘終了時に敵の状態をすべて破棄する。 |
| BTL-904 | 戦闘終了時に、味方の麻痺・睡眠・防御・かばうを解除する。HP・SP・死亡・毒は保持する。 |
| BTL-905 | 味方が同一ターン中に蘇生された場合、まだ実行されていない予約行動が残っていれば実行できる。ターン開始時点で死亡していた者には、そのターンの予約が存在しない（BTL-101）。 |
| BTL-906 | `BattleSession` は戦闘の中断時および全滅時に破棄する。保存しないことはSAV-204に従う。 |

## 2. 受け入れ条件

`tech/testing.md` のテスト基盤に従い、ヘッドレスで検証する。

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| B01 | 固定ダメージ倍率1.0、命中成功を注入し、代表5ケースを計算する | `data/` の値と式から算出した期待値に一致する。現行データでの期待値は 27、40、55、40、18 | BTL-003, 010, 013〜015, 017, 018, 020 |
| B02 | 攻撃対象が先行する行動で死亡する。味方への回復対象が死亡している | 敵への単体攻撃は生存敵の出現順先頭へ再照準する。味方への回復は再照準せず不発とし、SPを消費しない | BTL-207, 208, 205 |
| B03 | 毒の継続ダメージと直接攻撃を、それぞれ睡眠中の対象へ与える | 毒では解除しない。直接ダメージでは解除する | BTL-412, 410 |

## 2. 数値記法（GLS-1xx）

| ID | 規則 |
| --- | --- |
| GLS-100 | `clamp(x, a, b)` は `x` を `a` 以上 `b` 以下に制限する。 |
| GLS-101 | `floor(x)` は小数点以下を切り捨てる。`ceil(x)` は切り上げる。 |
| GLS-102 | `max(a, b)` / `min(a, b)` は大きいほう / 小さいほうを返す。 |
| GLS-103 | 確率は0〜1の実数で表す。 |
| GLS-104 | 乱数 `u` は `[0, 1)` の実数とする。確率 `p` の判定は `u < p` を成功とする。 |
| GLS-105 | 整数範囲の抽選は両端を含む。`一様整数(0, 5)` は0〜5の6通りから等確率で選ぶ。 |
| GLS-106 | お金の単位はG。整数で扱い、下限を0とする。負の所持金・借金は発生しない。 |
| GLS-107 | HP・SP・基礎能力・攻撃力・守備力は整数で扱う。 |
| GLS-108 | 基礎能力の最低値は1、最大HPの最低値は1、最大SPの最低値は0とする。 |

## 3. 乱数系列（GLS-2xx）

| ID | 規則 |
| --- | --- |
| GLS-200 | 乱数は用途別に独立した系列を用いる。系列は `encounter`、`battle`、`loot`、`creation` の4つとする。 |
| GLS-201 | 冒険者ごとの成長乱数 `growth_rng` は、冒険者の作成時に `creation` 系列からseedを引いて生成する。冒険者ごとに独立して保存する。 |
| GLS-202 | 各系列の用途は次のとおり。`encounter` は遭遇残り歩数と出現編成の抽選のみ、`battle` は戦闘の解決、`loot` は戦闘ドロップ、`creation` は `growth_rng` のseed生成。 |
| GLS-203 | UIの開閉、一覧の並べ替え、入力の選び直し、セーブは乱数を消費しない。 |
| GLS-204 | 乱数は判定を行う箇所でのみ引く。あらかじめまとめて引き置きしない。 |
| GLS-205 | 対象を列挙する順序は、味方をパーティ順、敵を出現順とする。 |
| GLS-206 | 各系列のseedとstateは10進文字列として保存する（SAV-2xx）。 |

## 4. 用語（GLS-3xx）

| ID | 用語 | 定義 |
| --- | --- | --- |
| GLS-300 | SP | スキルの消費資源。本作ではTPという呼称を用いない。 |
| GLS-301 | 制作用マップ | 制作者が `TileMapLayer` で定義する30×30の2Dセルデータ。`tech/map-authoring.md` が扱う。 |
| GLS-302 | ミニマップ | プレイヤーに表示する自動記録の地図。制作用マップとは別の概念（DNG-4xx）。 |
| GLS-303 | 登録者 | ギルドに登録済みの冒険者。最大20人。 |
| GLS-304 | パーティ | 登録者から選んだ編成。順序が意味を持つ。人数の規則はPTY-102, PTY-103に従う。 |
| GLS-305 | 待機者 | 登録済みでパーティに含まれていない冒険者。 |
| GLS-306 | 参加者 | 戦闘の開始時にパーティへ含まれていた冒険者。 |
| GLS-307 | ゲーム日数 | セーブデータ内の整数の日付。現実の時刻とは無関係（TWN-5xx）。 |
| GLS-308 | 遭遇残り歩数 | ランダム戦闘が発生するまでの残り歩数（DNG-3xx）。 |
| GLS-309 | 忍び足の残り効果歩数 | スキル `silent_steps` の効果が続く残り歩数（DNG-3xx）。遭遇残り歩数とは別の値。 |
| GLS-310 | 向き | 北0・東1・南2・西3の整数で表す。 |

## 5. 識別子（GLS-4xx）

| ID | 規則 |
| --- | --- |
| GLS-400 | データのIDは半角英小文字とアンダースコアのみで構成する。表示名とは分離して管理する。 |
| GLS-401 | すべてのIDは種別ごとに一意とする。セルイベントのIDはフロアをまたいで全体で一意とする。 |
| GLS-402 | セルイベントのIDは `{floor_id}_{suffix}` の形式とする。suffixは `entry`、`exit`、`shortcut`、`door`、`chest_a`、`chest_b`、`inscription`、`boss`。魔法陣のみ全体IDの `warp_depths` とする。 |
| GLS-403 | 冒険者のIDは単調増加する整数とする。削除しても再利用しない。 |

## 6. 版番号（GLS-5xx）

用途の異なる3つの版番号を用いる。混同しない。

| ID | 版番号 | 対象 | 初期値 |
| --- | --- | --- | --- |
| GLS-500 | 文書の版 | 本文書群 | v1.0 |
| GLS-501 | `content_version` | `data/` の固定データ | 0.1.0 |
| GLS-502 | `schema_version` | セーブファイルの形式 | 1 |

| ID | 規則 |
| --- | --- |
| GLS-503 | `content_version` が `0.x` の間は、旧セーブデータとの互換を保証しない。`1.0.0` 到達時点で互換保証を開始する。 |

# 状態遷移

ゲーム全体の状態と遷移、入力の遮断、未保存の扱いを定義する。

**この文書が扱わない範囲**

| 関心事 | 所在 |
| --- | --- |
| 各状態の画面レイアウト・キー割り当て・演出秒数 | `tech/presentation.md` |
| 施設内の操作と料金 | `spec/20-town.md` |
| 探索中の移動とイベント | `spec/40-dungeon.md` |
| 戦闘の進行 | `spec/50-battle.md` |
| セーブ・ロードの手順、自動保存しないこと | `spec/70-save.md` |
| 登録者0人の間に街で使える操作 | `spec/20-town.md`（TWN-110〜113） |
| 戦闘中に利用できない操作 | `spec/50-battle.md`（BTL-108） |
| 設定の項目と保存先 | `tech/presentation.md`（PRS-4xx） |
| 画面とサービスの責務分割 | `tech/architecture.md` |

## 1. 状態（FLW-0xx）

| ID | 状態 | 内容 | 遷移先 |
| --- | --- | --- | --- |
| FLW-001 | TITLE | 「はじめから」「つづきから」「設定」「終了」 | NEW_GAME / LOAD / SETTINGS / アプリ終了 |
| FLW-002 | NEW_GAME | セッションを初期化し、短い導入を表示する | TOWN |
| FLW-003 | LOAD | 5スロットの一覧 | TOWN |
| FLW-004 | TOWN | 街の背景、5施設、ダンジョンへ、メニュー、セーブ、タイトルへ | FACILITY / DEPARTURE / MENU / SAVE / TITLE |
| FLW-005 | FACILITY | ギルド・教会・商店・宿屋・酒場の専用画面 | TOWN |
| FLW-006 | DEPARTURE | 出発先の選択 | EXPLORATION / TOWN |
| FLW-007 | EXPLORATION | 3D視界、ミニマップ、パーティ状態、危険度、階層名 | MENU / EVENT / BATTLE / TOWN |
| FLW-008 | EVENT | 会話、宝箱、階段、魔法陣などの確認 | EXPLORATION / 別フロア / TOWN / BATTLE |
| FLW-009 | BATTLE | 敵画像、味方一覧、コマンドと対象の選択、行動ログ | REWARD / EXPLORATION / GAME_OVER |
| FLW-010 | REWARD | 経験値・お金・ドロップ・成長結果、所持品の整理 | EXPLORATION / ENDING |
| FLW-011 | GAME_OVER | 「全滅した…」。決定で戻る | TITLE |
| FLW-012 | ENDING | 短いクリア文章。決定で閉じる | TOWN |
| FLW-013 | MENU | 所持品、装備、スキル、能力、地図、設定、タイトルへ | 元のTOWNまたはEXPLORATION / SETTINGS |
| FLW-014 | SETTINGS | マスター音量、フルスクリーン、戻る | 呼び出し元のTITLEまたはMENU |

## 2. 遷移の条件（FLW-1xx）

| ID | 規則 |
| --- | --- |
| FLW-101 | LOADで選択できるのは、SAV-4xxの検証に合格したスロットに限る。 |
| FLW-102 | ロードはTITLEからのみ実行できる。進行中のセッションから別のスロットを読み込むことはできない。 |
| FLW-103 | DEPARTUREの出発先は、第1ダンジョン1Fと、起動済みの場合の第2ダンジョン1F魔法陣とする（DNG-5xx）。 |
| FLW-104 | 出発にはパーティが1〜4人であり、そのうち生存者が1人以上であることを要する。死亡者を含む編成での出発は可能とする。 |
| FLW-105 | BATTLEからEXPLORATIONへ戻るのは逃走の成功時のみとする（BTL-5xx）。 |
| FLW-106 | GAME_OVERはTITLEへ戻る。街への自動復活は行わない。保存の扱いはSAV-004に従う。 |
| FLW-107 | REWARDは、最終ボスの撃破時のみENDINGへ進む。それ以外はEXPLORATIONへ戻る。 |
| FLW-108 | TITLEへ戻る際に、進行中のセッションを破棄する。 |
| FLW-110 | MENUへ遷移できるのはTOWNとEXPLORATIONに限る。TOWNでの可否はTWN-110に従う。 |
| FLW-111 | SETTINGSはTITLEとMENUの両方から開ける。いずれも同一の画面とし、二重に実装しない。 |
| FLW-112 | SETTINGSは進行中のセッションを参照しない。セッションが存在しない状態（TITLE）でも開ける。 |
| FLW-113 | SETTINGSを閉じると、必ず呼び出し元の状態へ戻す。TITLEから開いた場合にTOWNへ遷移しない。 |

## 3. 入力の遮断（FLW-2xx）

| ID | 規則 |
| --- | --- |
| FLW-200 | モーダルの表示中と、移動・行動の演出中は、背景への入力を遮断する。 |
| FLW-201 | MENUとEVENTの表示中は、ゲーム日数、敵、遭遇残り歩数のいずれも進めない。 |
| FLW-203 | 確認ダイアログの初期選択は常に取消側とする。 |
| FLW-204 | 入力できない状態を `GameFlow` と `BattleSession` が明示的に保持する。画面側で独自に判断しない（ARC-2xx）。 |

---

## 4. 未保存の扱い（FLW-3xx）

| ID | 規則 |
| --- | --- |
| FLW-300 | 進行中のセッションに未保存の変更がある状態で、TITLEへ戻る操作またはウィンドウを閉じる操作が行われた場合、「未保存の進行は失われます」の確認を表示する。 |
| FLW-301 | 設定はゲームの進行とは別に保存する。設定の変更だけで未保存フラグを立てない（PRS-4xx）。 |
| FLW-303 | クリア直後および魔法陣の起動直後であっても、セーブせずに終了すればその進行は失われる。これを仕様として許容する。 |

---

## 5. クリア処理（FLW-4xx）

| ID | 規則 |
| --- | --- |
| FLW-400 | 最終ボスに勝利した場合、通常の報酬処理（BTL-7xx）を完了させてからクリア処理へ進む。 |
| FLW-401 | 続いてクリアフラグを立て、ENDINGで短いクリア文章を表示する。 |
| FLW-402 | ENDINGを閉じるとTOWNへ戻す。HP・SPの自動回復と自動保存のいずれも行わない。 |
| FLW-403 | 「クリアしました。街でセーブすると記録されます」を表示する。 |
| FLW-404 | クリア後も街と探索を継続できる。最終ボスの復活はTWN-605に従う。 |

## 6. 受け入れ条件

| ID | 前提・操作 | 合格条件 | 根拠 |
| --- | --- | --- | --- |
| FL01 | 進行中に未保存の変更を作り、TITLEへ戻る／ウィンドウを閉じる | いずれも確認を表示する。設定のみを変更した場合は表示しない | FLW-300, 301 |
| FL02 | パーティ全員死亡の状態で出発を試みる。生存者1人を含む1〜4人で出発する | 全員死亡では出発できない。生存者1人以上かつ1〜4人の場合のみ出発できる | FLW-104 |
| FL06 | TITLEから設定を開いて変更し、閉じる。続いてMENUから設定を開く | TITLEから開けて変更が保存される。閉じるとTITLEへ戻る。MENUから開いた設定に同じ値が反映されている | FLW-111〜113, PRS-401 |
| FL03 | MENUとEVENTを開いた状態で時間を置く | ゲーム日数・遭遇残り歩数のいずれも変化しない | FLW-201 |
| FL04 | 最終ボスに勝利する | 報酬処理、クリアフラグ、ENDING、TOWNの順に進む。自動保存も自動回復も発生しない | FLW-400〜403 |

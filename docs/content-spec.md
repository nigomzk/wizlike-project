# 初回版データ一覧

固有名・数値・仮マップを含む初期データとして採用する。実プレイでのバランス調整前であり、面白さを検証済みという意味ではない。初回データのcontent_versionは0.1.0。

識別子は半角英小文字とアンダースコアで固定し、表示名とは分離する。記載のない職業・アイテム・敵・スキルを実装者判断で増やさない。金額はG、能力は整数、確率は%表記。表の「全職」は5職すべて。

### 6.1 仮マップの厳密な作成手順

以下は動作検証用の共通形状であり、最終的な地形はユーザーがTileMapLayerを編集して差し替える。各フロアは独立シーンとし、同じシーンの実行時複製だけで済ませない。

1. 座標範囲はx,yとも0〜29。まず900セルを壁で埋める。外周は壁のまま。
2. y=3,9,15,21,27 の各行についてx=3〜26を床にする。
3. x=26,y=3〜9、x=3,y=9〜15、x=26,y=15〜21、x=3,y=21〜27を床にして蛇行する一本道を作る。
4. x=10,y=4〜8を床にし、(10,6)を未開近道にする。近道は南側(10,7)から北を向いて調べたときだけ初回開通可。開通後は双方向通行可。これが1本目の折り返しの短縮路になる。
5. (16,15)を通常扉にする。両側から調べて開けられ、一度開ければ閉める操作は不要。開状態は永続保存。
6. (18,14)に宝箱A、(8,22)に宝箱Bを置く。いずれも隣接通路から調べる。宝箱セルは歩行不可。
7. 開始地点(3,3)、終了地点(26,27)。開始時の向きは東、終了地点から逆向きに到着する場合の向きは西。
8. 階段等のイベントとボスは下表に従って配置する。各階層に(5,4)の調べる会話碑を追加する（歩行不可、未踏床を開示しない）。

| フロア | (3,3) | (26,27) | その他 |
| --- | --- | --- | --- |
| ruins_f1 | 街への出口 | ruins_f2開始へ下り階段 | 街からここへ出発 |
| ruins_f2 | ruins_f1終了へ上り階段 | ruins_f3開始へ下り階段 | 初到達で品揃えB |
| ruins_f3 | ruins_f2終了へ上り階段 | depths_f1開始へ接続通路 | (22,27)にgatekeeper |

門番セルを経由しないと第2ダンジョンに到達できない。ラスボスは進入時に戦闘を起こし、勝利後に街へ戻るため、奥の通常床に重要な報酬は配置しない。

イベントIDは `{floor_id}_{suffix}`。suffixはentry、exit、shortcut、door、chest_a、chest_b、inscription、boss。魔法陣だけは全体ID `warp_depths`。最終フロアにexitイベントは置かない。

## 8. 物語・素材・文章の範囲

- 仮タイトル「迷宮踏査録」。舞台は遺跡の傍らにある小さな街。冒険者を登録して遺跡の奥を調べるという導入。
- 導入文：「街の外れに眠る遺跡で、奥へ続く道が見つかった。ギルドに仲間を登録し、迷宮の最深部を目指そう。」
- 第1ボス予告：「石の門番が道をふさいでいる。」撃破初回：「門番は崩れ落ちた。奥には水晶に覆われた迷宮が続いている。」再撃破は「門番を倒した。」のみ。
- 最終ボス予告：「迷宮の主が姿を現した。」エンディング：「迷宮の主を倒し、街に静けさが戻った。あなたたちの踏査は、ギルドの記録に刻まれる。」
- 会話碑はフロア順に「帰還の糸を忘れるな」「近道は反対側から開く」「雷は石を砕く」「魔法陣は街につながる」「氷の術師は火に弱い」「力をためた敵には防御を」。何度でも読め、アイテムやフラグ報酬なし。
- 街背景1枚、顔10枚、敵画像14枚、地形用タイルアイコンとUIアイコンを用意する。初期版は自作の単純図形・色分け・ラベルによる仮素材で可。画像差し替えでロジック変更を要しない構成にする。
- 効果音は決定・取消・衝突・攻撃・回復・勝利の6種、BGMは初回版ではなし。効果音も簡単な自作音で可、外部有料素材は必要条件にしない。

## 9. 紙上の検算と実プレイで確認する点

乱数倍率1.0、命中成功時の例：

| 条件 | 期待する値 |
| --- | --- |
| Lv1戦士＋古びた剣がスライムを通常攻撃 | ATK15、`2×15-3=27`ダメージ。90%倍率時24なので必ず一撃ではない |
| 同戦士がスライムに強撃 | 基礎27×1.5、100%時40ダメージ |
| Lv1魔術師の火球→スライム | `(14+2×13-3)×1.5`を切捨て、55ダメージ |
| Lv1僧侶の癒やし | `18+2×11=40`回復 |
| 狼の通常攻撃→Lv1戦士＋布の服 | `2×14-(8+2)=18`ダメージ |
| Lv1パーティ4人の宿泊 | `4×(5+2)=28G`、1日経過 |
| スライム2体に勝利、4人生存 | 各12EXP、共有20G、個体ごとに粘液50%抽選 |
| 登録者を作成して初期装備2個を売却 | 2G。スライム2体の通常戦1勝は20G |
| Lv1→Lv5の累積経験値 | 480EXP。成長抽選4回×7能力 |

目標は、初期4人が無理なく数戦して帰還でき、訓練・装備購入で次の探索が少し長くなること。数値の紙上整合と実際の攻略難度は別に検証する。スライム相手の戦闘が作業になりすぎる、魔法火力が支配的、宿泊救済が常用前提になる、階層到達Lvが大きく外れる、といった場合は実装後にデータのみで調整し、変更値と理由を記録する。

# ゲームルール・画面仕様

初回版のゲームルールとする。

## 1. 初回版の範囲

Windows 11向け、日本語、ローカル1人プレイ。街で準備し、30×30マスのダンジョンを一人称で探索する。ダンジョンは2個、各3フロア。5職業、最大20人の登録者から1〜4人のパーティを組む。4人基準の固定難易度で、人数に応じた敵の補正はしない。

第一の面白さはHP・SP・消耗品を見て帰還を判断すること、第二は職業編成と戦闘攻略。任意クエストは資金や消耗品を補助する。敵の3Dモデル、自由移動、手描き地図、前後列、転職、キャラロスト、空腹、装備耐久、時間制限、オンライン、周回機能は初回版の対象外。

タイトルへ戻る・ウィンドウを閉じる際、進行中セッションに未保存の変更があれば「未保存の進行は失われます」の確認を表示。ロードはタイトルからのみ。設定はゲーム進行と別保存し、設定変更だけで進行の未保存フラグを立てない。

## 3. ニューゲーム・冒険者

- ニューゲームはゲーム内1日目、所持金300G、薬草5、解毒薬2、帰還の糸2。登録者・パーティは空、全探索記録・イベント・クエスト進行は未開始。
- 冒険者作成：名前（前後空白を除去後1〜12文字、改行不可）、職業、顔画像を選ぶ。同名可。作成確認後に単調増加IDを割り当て、登録者一覧へ追加する。途中キャンセルは何も消費しない。
- 顔画像は10種の仮ポートレート、全職で選択可能。能力に影響なし。登録後も名前・顔は無料で変更可、職業は変更不可。
- 初期装備はcontent-specの職業別最低武器と布の服を装備済みで支給。初期スキル習得済み、HP/SP満タン。装飾品なし。初期装備は各1Gで売却可能。登録の繰り返しで少額を得られることは許容する。
- ギルドでパーティの追加・外し・順序変更。1人を二重登録しない。街では0人も許容するが、出発には1〜4人かつ生存者1人以上が必要。死亡者を含めた出発は可能。
- ギルドで冒険者削除を選ぶと名前・レベルを示して確認。パーティからも外す。装備は共有所持品へ返す。返却すると30枠を超える場合は削除不可。IDは再利用しない。
- 待機者のHP/SP・毒・死亡・装備・習得スキル・経験値は保持。編成変更では回復しない。

## 4. 施設・お金・日数

お金は整数G、下限0。すべての購入・売却・訓練・治療・報告は、操作確定直前に条件を再検証して一括反映する。条件不足では料金・アイテム・進行を一切変更しない。

| 施設 | サービス・料金 |
| --- | --- |
| ギルド | 登録・編成・名前/顔変更・削除は無料。訓練は職業・必要レベル・未習得・所持金を確認してスキル表の料金で習得。死亡者も訓練可能 |
| 宿屋 | 登録者一覧から生存者を1人以上選び宿泊。1人につき `5 + 2×レベル` G。選んだ生存者のHP/SP全回復、毒は残す。1回の確定で日数+1。満タンでも料金を払って宿泊可。死亡者のみ・対象0人では宿泊不可 |
| 教会 | 解毒：1人10G。蘇生：1人 `20 + 5×レベル` G、HPは最大値の50%切り上げ、SPは死亡時の値を維持。治療対象の複数選択可。日数は進まない |
| 商店 | 買う・売る。購入数と金額と空き枠を事前表示。装備中の品は直接売れない。素材・消耗品は数量選択して売却可。買い戻し機能なし |
| 酒場 | クエストの受注・進行確認・報告。同時受注上限なし（全6件）、破棄なし、期限なし |

宿屋と教会に共通の「救済を受ける」を表示。以下で厳密に判定する。

1. 全登録者について、通常サービスで現在の不足を直す合計料金Cを計算する。
2. 生存者のHP/SPに不足があれば宿泊料金を加える。毒なら解毒料金も加える。死亡者は蘇生料金と、その後の全回復に必要な宿泊料金を加える（死亡者に毒はない）。
3. C>0かつ所持金<Cのときだけ救済可能。登録0人・全員完全回復では不可。
4. 「所持金○Gをすべて渡して、登録者全員を回復します」の確認後、所持金を0にし、全員の死亡・毒を治しHP/SPを満タンにする。日数は進まない。

この救済は資金不足による進行不能の回避を優先し、戦略的に利用することも禁止しない。

ゲーム日数は整数、初期1。宿泊取引が成立したときだけ+1。連泊ボタンは設けず、繰り返し宿泊可能。保存・ロード・現実の時刻・歩行・戦闘・救済では進めない。

第1ボスは `最終撃破日 == null または 現在日 - 最終撃破日 >= 30` なら存在する。再撃破時に最終撃破日を更新する。初回撃破フラグは永久保持し、通路・品揃え・クエスト解禁・魔法陣起動を巻き戻さない。ラスボスはクリアフラグ成立後に復活しない。街の出発画面に第1ボスの「未討伐／再出現までN日／再出現済み」を表示する。

## 5. 所持品・装備・報酬の容量

- 共有所持品は30枠。武器・防具・装飾品は各1個1枠。消耗品・素材は同IDごとに1枠9個まで。10個なら2枠。同種の部分スタックから詰める。
- 装備中の品は枠外。装備変更時は外す品と着ける品の差分を計算して容量を確認する。交換できない場合は何も変えない。装備で最大HPが下がった場合、現在HPを新しい最大HPに丸める。上がっても現在HPは増やさない。
- 装備変更・アイテム破棄は街・探索メニューで可能。死亡者の装備も変更可。アイテム破棄は数量を確認する。重要品は別辞書で保存し売却・破棄不可（初回版の進行解禁はフラグで行い、重要品データは0件）。
- 戦闘ドロップ：経験値・お金を先に確定。ドロップを一時獲得一覧に置き、空きに入れる／既存品を捨てる／獲得を諦めるを選ぶ。報酬画面を閉じる前に残りの破棄確認。再度画面を開いて二重取得できない。
- 宝箱：中身すべてを受け取れる場合だけ開封確定。容量不足なら整理案内を表示し、未開封のまま戻る。部分取得なし。
- クエスト：納品で消える品と報酬で増える品の両方を含めて容量を確認。全報酬が入らなければ報告不可。納品・報酬・完了フラグを一括確定する。
- 商店：容量不足時は購入不可。倉庫は初回版には設けない。

## 6. 探索・ミニマップ

### 6.1 移動と操作

論理位置は整数セル(x,y)、向きは北0・東1・南2・西3。前後移動と左右の平行移動は1セル、左右旋回は90度。壁・未開扉・範囲外へは移動不可。移動0.15秒、旋回0.12秒の演出中は追加入力を保持しない。演出完了時に次の入力を受け付け、キー長押しは完了後0.12秒間隔で繰り返す。Tween中断時も論理位置に描画位置を合わせる。

壁への衝突、旋回、調べる、メニュー、扉の開閉では歩数は進まない。前後・左右の成功移動は同じ1歩。床・階段・魔法陣・ボス床への侵入でも歩行毒は処理する。街からの出発・階段の到着・逃走による位置復元は歩数に数えない。

### 6.2 一歩の処理順

1. 入力可能・移動先通行可能を検証する。
2. 論理セルを移し、移動演出を行う。歩行毒を生存者ごとに `max(1,floor(最大HP×0.02))` 与える。ただしHPは1を下回らない。
3. 現在セルの踏破と隣接壁を記録する。斥候の探索効果があれば残り歩数を1減らす。
4. 足元イベント（階段・街出口・魔法陣・接続点・ボス）があれば優先処理し、この歩ではランダム遭遇カウントを減らさない。
5. それ以外は遭遇カウントを1減らす（探索効果が有効だった歩では減らさない）。0に達したら通常戦へ。

宝箱・扉・近道・会話は正面のセルを「調べる」で操作する。宝箱・会話は隣接して調べる対象で、そのセルには入れない。通常扉・近道は開通後に歩ける。階段・街出口・接続点に乗ると移動確認、「いいえ」なら留まる。同じセルに留まる間は再表示しないが「調べる」で再確認できる。到着直後は足元イベントを再発火させない。

### 6.3 遭遇

街から出発したとき・勝利したとき・逃走成功時に、残り歩数を一様整数 `12〜20` から抽選する。階層移動・ダンジョン間移動・イベント確認を断る操作では再抽選しない。特殊セル上での移動による遭遇回避は許容する。

通常戦の出現編成はフロア表の3編成から等確率抽選。先制・不意打ちは初回版に含めない。危険度は残り歩数9以上＝青、5〜8＝黄、1〜4＝赤。正確な数値は画面に出さない。

### 6.4 ミニマップ

画面右上に北固定の現在フロア全体30×30を表示、現在位置と向きを矢印で示す。未踏破床は黒。現在セルと、その東西南北の壁・調べる対象だけを発見記録に追加する。未踏破の隣接床は明かさない。

階段・魔法陣・ボス床は踏んだ時点で記録。扉・宝箱・近道・会話は隣接時に記録。地図メニューでは訪問済みフロアを切り替え、凡例と開封・開通状態を表示する。手描き・注釈・地図からの移動は不可。記録はセーブに含め、未保存の探索は全滅・ロードで失う。

### 6.5 帰還・ボス・クリア

第1ダンジョン1F出口と帰還の糸は街へ戻す。帰還の糸は探索中のみ使え、確認をキャンセルしたら消費しない。帰還時のHP/SP・毒・死亡は維持。斥候の探索効果は解除。

第2ダンジョン1F魔法陣は踏んで起動確認。拒否時は再訪か調べるで再確認。起動を承諾した時点で永久解禁し、続けて帰還するか選ぶ。街から到着した直後は帰還確認を自動表示しない。

ボスのいるセルへ入ると予告文を表示して戦闘開始（進入後の取消不可）。倒したボス床は通行可。ラスボス以外は30日後に同じ場所に復活する。第1ボスの奥から次ダンジョンへ移動可能で、逆方向にも戻れる。

ラスボス勝利では通常の報酬処理後、クリアフラグを立てて短いエンディングを表示し街へ戻す。自動回復・保存はしない。「クリアしました。街でセーブすると記録されます」を表示する。

## 7. 戦闘

### 7.1 数値の基本

HP・SP・基礎能力・攻撃力・守備力は整数。表示能力は装備補正込み。攻撃力=STR+武器攻撃力、守備力=VIT+防具防御力（装飾品のVIT補正はVITに先に加算）。敵は表にある攻撃力・守備力を直接使う。TECは魔法攻防と物理命中に使う。

`clamp(x,a,b)` はa〜bに制限、`floor` は切り捨て、`ceil` は切り上げ。確率は0〜1。乱数uは[0,1)、成功はu<p。整数範囲抽選は両端を含む。戦闘と探索、成長は別の乱数系列を用いる。

| 判定 | 式 |
| --- | --- |
| 物理命中 | `clamp(0.90 + 0.005×(攻撃側TEC-対象AGI), 0.60, 0.98)`。睡眠対象には1.0 |
| 魔法・回復命中 | 常に成功（状態異常のみ別判定） |
| 通常物理基礎値 | `max(1, 2×攻撃力 - 守備力)` |
| 物理スキル基礎値 | 上記×スキル倍率 |
| 魔法基礎値 | `max(1, スキル威力 + 2×攻撃側TEC - 対象TEC)` |
| 最終ダメージ | `max(1,floor(基礎値×属性倍率×防御倍率×かばう倍率×r))`、rは整数90〜110÷100 |
| 回復量 | `スキル威力+2×使用者TEC`、乱数なし、対象最大HPで上限 |
| 状態異常成功 | `clamp(基礎成功率 + 0.005×(攻撃側LUC-対象LUC),0.05,0.95)×対象の異常耐性倍率` |
| 行動速度 | `AGI + 一様整数(0,5)` |

属性倍率は通常1.0、弱点1.5、耐性0.5。物理耐性も同式。属性吸収・完全属性無効・クリティカルは設けない。防御コマンドはダメージ×0.5、かばうは×0.7（後述）。持続毒ダメージはこれらの倍率を使わない。

### 7.2 入力・順序

1. ターン開始：ターン専用の防御・かばうを解除。生存味方をパーティ順に入力する。睡眠中もコマンド予約は可能（実行時に眠っていれば不発）。死亡者は入力対象外。
2. 各味方に攻撃／スキル／防御／アイテムを割り当てる。全員入力後に「実行／選び直す」を表示。選び直しでは乱数を消費しない。逃走は別のパーティ共通操作として、通常戦の入力画面で選択する。
3. 実行確定後、敵は表の重み付き行動を選択し、敵味方の生存者全員に速度を1回ずつ抽選する。防御・かばうを優先群（priority=100）、その他を通常群（priority=0）とし、各群で速度の降順に並べる。同速は味方→敵、味方はパーティ順、敵は出現順。
4. 実行時に死亡ならスキップ。睡眠なら行動不可。麻痺なら25%で行動不可。行動できる場合のみ対象と費用を再検証し、SP/アイテムを消費して実行する。
5. 単体攻撃の予約対象が死亡していれば、生存敵の出現順先頭へ変更する。味方を対象とする回復等は自動変更せず、対象死亡・蘇生対象が生存など無効なら不発・消費なし。全体攻撃は実行時の生存対象を出現順に処理する。
6. 各行動後に全滅・勝利を判定する。敵全滅なら即勝利（ターン末の毒は発生しない）。味方全滅なら即ゲームオーバー。
7. 両陣営が残っていればターン末処理を行い、次ターンへ。

戦闘中のメニューから装備や並び順は変えない。SP不足のスキルは入力不可。同一ターンのアイテムは在庫数量までしか予約できない。入力を戻すと予約を解除し、アイテムを取り合わない。実行前の行動不能・対象無効ではSPもアイテムも消費しない。攻撃が外れた場合や異常付与に失敗した場合は消費済みとする。

防御は行動が実行された時点からそのターン末まで有効。かばうは指定した味方1人への単体ダメージ攻撃を騎士へ移し、騎士側の守備力・耐性で計算して0.7倍。全体攻撃・毒継続・回復には作用しない。付随異常も騎士が受ける。騎士が死亡・睡眠・麻痺ならかばうを停止する（麻痺の行動失敗抽選とは別）。複数の騎士が同一人をかばう場合はパーティ順が先の有効な騎士1人のみ。かばうの連鎖は起こさない。自分自身をかばう対象には選べない。

### 7.3 状態異常と死亡

毒・麻痺・睡眠は併存可能。同じ異常の重ね掛けは強度を増やさず、期限を長い方へ更新する。状態異常単独スキルは命中判定なしで付与確率だけ判定。ダメージ付随異常はダメージ命中後に判定する。

| 状態 | 効果・解除 |
| --- | --- |
| 毒 | ターン末に最大HPの5%切り上げ（最低1）を失う。戦闘中は死亡しうる。自然解除なし。解毒薬・解毒スキル・教会・死亡で解除。探索歩行は別の2%式 |
| 麻痺 | 行動直前に25%で行動を失う。付与ターンを含め3回のターン末処理後に解除。戦闘終了でも解除 |
| 睡眠 | 行動不可。付与ターンを含め2回のターン末処理後に解除。正の直接ダメージを受けた直後に解除、毒では起きない。戦闘終了でも解除 |
| 死亡 | HP=0。すべての異常・防御・かばうを解除。SPは保持。通常回復不可。蘇生のみで解除 |

ターン末は生存者全員の毒ダメージを同時適用し、その後全滅を判定。両陣営同時全滅ならゲームオーバー優先。残っていれば麻痺・睡眠の残りターンを1減らす。期間の短縮は付与されたターン末から始める。

戦闘終了時に敵状態は破棄。味方の麻痺・睡眠・ターン効果は解除し、HP/SP・死亡・毒は保持。蘇生直後に未実行の予約行動が残っていれば実行できるが、ターン開始時に死亡していた者にはそのターンの予約はない。

### 7.4 逃走

通常戦のみパーティ共通で選択。味方の個別コマンドを破棄し、敵の行動前に1回判定する。睡眠・麻痺でも生存していれば逃走判定に参加可能。

`p=clamp(0.60+0.01×(生存味方の平均AGI-生存敵の平均AGI),0.20,0.95)`。

成功：経験値・お金・ドロップなし。倒した敵も含め報酬なし。討伐クエストのカウントも加算しない。遭遇したセルで探索を再開し、遭遇歩数を再抽選。

失敗：味方は誰も行動せず、敵全員が通常の速度順で行動し、ターン末へ進む。防御は付与しない。ボス戦では逃走を無効表示する。

## 8. 報酬・成長・クエスト

戦闘勝利時、全敵の経験値とGを合計し、生存している参加者N人へ `floor(合計EXP/N)` を配る。余りは破棄。レベル上限者も配分人数に含め、その者の受取分は破棄（他へ再配分しない）。お金は共有。討伐クエストは勝利確定時に、受注中の対象敵数を上限まで加算する。逃走・全滅で進捗を加算しない。

各敵のドロップは1種類、各個体ごとに表の確率で1回抽選。固定種別・個数で、一体から複数種類は落とさない。

累積経験値で管理し、レベルLに必要な累積値は `20×(L²-1)`。レベル1は0、2は60、5は480、8は1260、12は2860、16は5100、20は7980。次レベルまでの追加経験値は `40×L+20`。複数レベルを跨ぐ場合は1レベルずつ成長抽選する。レベル20の累積経験値は7980に固定する。

成長は能力ごとに独立して `固定増加値 + Bernoulli(職業別確率)` を加算。HP/SPも同じく追加は0か1。成長乱数は冒険者別に保存する。レベルアップで増えた最大HP/SPと同じ分だけ現在値を増やす。基本能力STR等の低下はない。成長結果を一覧表示し、まとめて閉じられる。

クエストはLOCKED→AVAILABLE→ACTIVE→COMPLETEDの順。解禁条件成立でAVAILABLE、受注でACTIVE、酒場の報告でCOMPLETED。条件達成だけでは自動報告しない。納品品は報告時に消費。討伐数は受注後のみ計上し、既存所持素材は納品可。報告には生存パーティメンバー1人以上を必要とする。

クエスト経験値は報告時の生存パーティへ戦闘と同じ方法で配分し、その場で成長する。報告後にパーティ変更しても再配分しない。クエスト詳細に合計EXP・現在の1人あたりEXP・G・アイテムを明示する。

## 9. 仕様上の意図的な許容

- 初期装備の登録・売却で1人あたり2Gを繰り返し得られる。低利益にする方針を採用し、追加の登録費用や売却禁止は設けない。
- 少人数で報告するとクエスト経験値を集中できる。
- 救済の条件を満たすよう所持金を使い切る遊び方は可能。
- 同じセーブから同じ成長操作をすれば同じ成長結果になる。成長乱数の保存で単純なロードし直しによる引き直しを抑える。
- 30泊してボスを再出現させることは可能。ただし通常の宿泊料金が必要。
- クリア直後・魔法陣起動直後でも、セーブせず終了すれば進行は失われる。
